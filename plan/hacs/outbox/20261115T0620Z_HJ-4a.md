## 3. The lattice (the one real choice), with proofs

The lattice is **not** `brandt_export.py`'s Hecke-stable hull, and it is not chosen per run. It is
  Λ_c := N_c^{−m} · span_ℤ{Q_{x₁}⋯Q_{x_m} : x_i ∈ (O_r(I_c)⁰)^#},  n = 2m,  Q_x(X,Y) = (X,Y) s(x) J (X,Y)ᵀ,  J = [[0,1],[−1,0]],
where R⁰ is the trace-zero part of R, # is the dual for trd(xy), and s is symn.py's splitting.
- (a) **ρ_n(γ)∏Q_{x_i} = ∏Q_{γ x_i γ̄}.** Proof: Q_x((X,Y)g) = (X,Y)·g s(x) J gᵀ·(X,Y)ᵀ, and gJgᵀ = det(g)J. Hence
  g s(x) J gᵀ = det(g)·g s(x)g⁻¹·J, i.e. ρ₂(g)Q_x = Q_{g x adj g}. Multiplicativity of ρ_n gives the product.
  So Λ_c is Γ_c-stable: conjugation by a unit preserves O_c⁰ and the trd form.
- (b) **Hecke integrality, termwise.** Put g = conj(δ)/N_c = ℓβ⁻¹. Then g x ḡ = (ℓN_{c′}/N_c)·β⁻¹xβ, and
  β⁻¹O_{c′}β = O_r(J). Now ℓ·O_r(J) ⊂ O_c and ℓ·O_c ⊂ O_r(J), because ℓI_c ⊂ J ⊂ I_c. By duality
  ℓ(O_r(J)⁰)^# ⊂ (O_c⁰)^#. Hence ρ(g)Λ_{c′} ⊂ N_{c′}^{−m}(N_{c′}/N_c)^m Λ′(O_c) = Λ_c.
  For Π_D (J = P_D I_c, O_r(J) = O_c) the same computation gives ρ(g)Λ_{c″} ⊂ D^m Λ_c. So **Π_D/D^{m} is an integral
  involution** (checked: "Pi_D divisible by D^(n/2)").
- (c) **Intrinsic.** Take L ↦ Lα. Then N ↦ N·nrd α, O_r ↦ α⁻¹O_rα, and ρ(α⁻¹)∏Q_{x_i} = nrd(α)^{−m}∏Q_{α⁻¹x_iα}.
  So ρ(α⁻¹)Λ(L) = Λ(Lα), and M_Z = {Φ : Φ(L) ∈ N(L)^{−m}Λ′(O_r(L)) for all L} depends on no choice: not the
  representatives, not the class order, not the ops.
  The *basis* (HNF in coordinates of Λ′(O)) does depend on the representatives and on O. So k > 2 records carry
  `canonical: false` together with the new optional `lattice_intrinsic: true`. F is determined up to block GL_d(ℤ)
  conjugacy; compare records by `charpoly_Z`.
- (d) **At p ∤ D this is exactly the stage-01 seed lattice.** Under ι_p, (M₂(ℤ_p)⁰)^# = {[[α,β],[γ,−α]] : 2α, β, γ ∈ ℤ_p}.
  Its Q_x = −βX² + 2αXY + γY² run through all of Sym²(ℤ_p²), at p = 2 too. Products of X², XY, Y² span Sym^{2m}(ℤ_p²).
  Changing the splitting s ↔ ι_p multiplies Q by det(g)^{−1}, a single scalar. So
  Λ_c ⊗ ℤ_p = (scalar)·ρ_n(x_{c,p}) Sym^n(ℤ_p²), and M_Z ⊗ ℤ_p is Brandt(O^×; Sym^n(ℤ_p²)) of def:s01-brandt, via the
  dictionary F(x) = x_p·f(x) of rem:s01-dictionary.
  Consequence: **at every p ∤ D, the p-parts of congruence modules and the p-adic valuations of Gram determinants (determinants up to p-adic units) of M_Z are lattice-independent invariants** (audit m6).
  This settles the HJ-4b stretch item ("canonical Sym^n lattice at k > 2") for level O^× and p ∤ D. At p | D the lattice
  is the stated choice (O⁰)^#.
- Comparison: symn.py's ℚ-form V^φ and our ℚ-form V′_ℚ = ℚ·{∏Q_x} are both ρ(s(B))-stable ℚ-forms of an absolutely
  irreducible representation. So they differ by a K^×-scalar, and the char-polys are identical (checked, 66/66).

## 4. API (for workers C = HJ-7 and D = HJ-8)

Header: `code/hacs/src/hacs/Registry/JL/quat/BrandtSym.h`, namespace `hacs_jl`. Types: `Z = nf::BigInt`,
`Q = nf::BigRational`, `ZMat`/`QMat` = `vector<vector<…>>` (row-major, `M[i][j]`), and `QB` = `array<Q,4>`, the
coordinates (c0, c1, c2, c3) of c0 + c1 i + c2 j + c3 k.
```cpp
MaxOrder O(D); ClassSet C(O);
BrandtSym M(C, n /* = k-2 */, BrandtSym::Options{/*canonical_order=*/true});
int M.rank(), M.h(), M.n(); i64 M.D(), M.a(), M.b(); int M.offset(c);    // block c = basis [offset(c), offset(c)+dim)
const std::vector<SymClass>& M.classes();  // per class: I, N, gamma (=|Gamma_c| incl. -1), w, units (all of Gamma_c,
                                           //   QB), order_basis (O_r(I_c)), dual0 ((O_r^0)^#), H (Lambda_c basis, base
                                           //   coords), Zinv (invariant basis, HNF in Lambda_c coords), E (same, base
                                           //   coords), EK (same, K-coords of X^{n-t}Y^t), dim()
std::vector<int> M.gammas(), M.dims();
// coefficients, column convention ([C] def:rhon): column j = image of basis vector j
KMat   rho_K(a, b, const QB& x, n);          // symn.py sym_matrix(split(x), n) over K = Q(sqrt a)
QMat   M.rho_base(const Vec4& g_in_O_coords, i128 den = 1);   // on Lambda'(O) = Z^{n+1}
ZMat   M.rho_base_int(const Vec4& g);         // integer for g in O (throws otherwise)
QMat   M.rho_class(int c, const QB& g);       // on Lambda_c; integer for g in O_r(I_c)
// operators on M_Z (rank x rank, column convention T b_j = sum_i T[i][j] b_i)
ZMat   M.T(i64 ell);                          // ell prime, ell not | D
ZMat   M.Pi(i64 p);                           // p | D: Pi_p; p == D: Pi_D = W_D (unnormalised, Pi_D^2 = D^n)
auto   M.terms_T(ell), M.terms_Pi(p);         // the raw Hecke correspondence: per class c, list of {src c', g in B}
ZMat   M.assemble(terms);                     //   with (T Phi)(I_c) = sum rho_n(g) Phi(I_c')
// pairing (C7)
QMat   M.gram(BrandtSym::Weight::w | ::gamma, bool divide = true);  // sum_c B_c / w_c  (divide=false: sum_c w_c B_c)
const QMat& M.gram_block(c);                  // B_c = N_c^n beta_n on the class block
Z      BrandtSym::denominator_lcm(G);  ZMat BrandtSym::scale_to_int(G, s);   // integer form s*G
bool   M.self_adjoint(const ZMat& A, Weight);
// exact helpers (namespace symz): charpoly (low->high), mul, is_scalar, hnf_rows, left_kernel,
//   restrict_to_eigenspace(T, A, lambda), reduce_mod(A, ell^K) (the module mod ell^K), fnv_text
```

NumberField/{BigInt,BigRational}.cpp` (+ `Sha256.cpp` for the tools).
Cost (single thread): D = 13, k = 18, T₄₇ about 1 s; D = 17 with 14 ops + Π + Gram + writer checks:

## 6. Deviations (disclosed)

1. **Lattice ≠ Lane B's hull.** §3 replaces `brandt_export.py`'s Hecke-stable hull (which depends on the ops and on symn.py's
   representatives). F matrices are therefore not comparable entry-wise with Lane B's k > 2 records; char-polys are
   (66/66). The new optional field `lattice_intrinsic` was added to the v2 record without a version change, as §1a of
   the format allows.
2. **"char_ℤ = HJ-A1 on the extended grid"** (plan §4 HJ-4) was not compared with HJ-A1 records. Instead PARI's newspace
   was used for every ℓ < 20 and the composite D (374/374). The HJ-A1 comparison is still open.
3. **Composite D** has no stage-01 JSON. It is checked by the relations above and by PARI.
4. **Gram "as integer matrices"** is delivered as `scale · G` with the scale recorded. ⟨,⟩_w has denominators w_c, and
   β_n has binomial denominators. The exact rational Gram is also given.
5. **Π is unnormalised** (Π_D² = D^{k−2}, as pi_sign.json). The integral involution Π_D/D^{(k−2)/2} is not a separate API
   call.
6. **Not wired into `hacs` / CMake**, as for HJ-1/2. The self-test is standalone and not a registered validation (HJ-11).
7. `quat_selftest` reports 8104 checks, not the 8084 of the brief (see §2). Nothing in the HJ-1/2 code changed.
8. `hj4_symn_mfcheck.json` records commit `0f1ab7ee…-dirty`, because the uncommitted `hj4_symn.json` was in the tree
   when it ran. Its `params.source_sha_commit` is the clean commit of the native results.
