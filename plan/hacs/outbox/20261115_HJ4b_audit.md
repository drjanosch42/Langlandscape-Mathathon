- *Definition.* (B3) is def:s01-NUp word for word: ϖ_j = ι⁻¹[[ℓ, j], [0, 1]], lower-row U₁ convention, datum
  d = e·x⁻¹ as in `up.py` (v(k) = e₂k⁻¹). Derived: the lattice of xϖ_j has ℓ-line (1, −j), which is not the datum
  line (0, 1); the U′_p representatives [[1, 0], [p^s j, p]] give the datum line. This is what `terms_hecke` and
  `terms_Up_prime` implement (BrandtLevel.cpp:243-255, 357-379).
- *No p^{k/2−1}.* Rerun: the 60 U_ℓ char-polys equal PARI's classical ones, with x² − a_ℓx + ℓ^{k−1} on the ℓ-old part,
  k = 2, 4, 6. Extra check by this audit (computed, O₀(q), D ≤ 13, q ∈ {2,3,5}, k = 2, 4, 6, 39 cells):
  **U_q s0^* = s0^* T_q − s1^*** and **U_q s1^* = q^{k−1} s0^***, exactly, in all cells.
- *Right way round.* U_p π^* = π^* U_p holds and fails for U′_p (rerun at s = 1, 2, 3; also recomputed from `up.json`

  45/45 cells, so U_q = −W_q on the q-new part (classical a_q = −w_q q^{k/2−1}, W unnormalised).

**2. The up.json comparison — transpose justified; the search does not hide an error.**
- *Transpose.* `up.json` stores homological matrices, M[t, s] = coefficient of [x_t] in T[x_s] (`up.py` docstring). Ours act
  on functions in column convention; at k = 2 with all stabilisers trivial that matrix is Mᵀ. `json_T` and the π block
  ((π_*)ᵀ placed at rows S₂, columns S₁) do exactly this (brandtlevel_selftest.cpp:137-143, 236-241).
- *Can a permutation hide an error?* `match_permutation` is a complete backtracking search with operators matched by
  name, so only a symmetry of the data can hide a swap. Computed from `up.json` at S₂ (permutation invariants):
  tr(U_p⟨2⟩) = 0 but tr(U_p⟨2⟩⁻¹) = 30; tr(U_p²T₂) = 180 but tr(U_p²T₂ᵀ) = 90; T₂ᵀ = ⟨2⟩T₂ holds and T₂ᵀ = ⟨2⟩⁻¹T₂ fails;
  ⟨2⟩ has order 10. So inverting the diamond, or transposing T₂, cannot be absorbed once U_p is fixed.
- The one variant that no single-level invariant can exclude is transposing everything (U_p ↔ U′_p, T₂ ↔ ⟨2⟩T₂,
  ⟨2⟩ ↔ ⟨2⟩⁻¹), since U_pᵀ = U′_p. It is excluded by the joint match with the π block (its position fixes the direction)
  together with U_p π^* = π^* U_p ≠ for U′_p, both of which are in the self-test. S₁ has 2 points and tests nothing.
- Not determined: whether a permutation for the all-transposed variant exists at S₂ alone (see m3).

## 4. Findings (all minor)

- **m1** `tests/brandtlevel_selftest.cpp:319, 329, 385-393, 410-411, 419-437`. The sign tests try one sign first and
  record it even when both hold. In the committed grid N1 ∈ {3, 4, 5} has ⟨ℓ⟩ = ⟨ℓ⟩⁻¹ at even weight, so only the U₁(15)
  cell decides the sign claimed in `BrandtLevel.h:47`. Add cells such as U₁(7), U₁(9), U₁(13) and record whether the
  other sign also holds. The signs themselves are right (§2 item 3).
- **m2** `BrandtLevel.h:44` and `plan/hacs/outbox/20261115T0655Z_HJ-4b.md:77` call (s0^*, s1^*) "the weight-k Ihara map";
  `TreeK.h:9` has ι = (s₀^*, −s₁^*). State that the consumer applies the minus sign.
- **m3** `tests/brandtlevel_selftest.cpp:175, 245` (`Brandt2.cpp:141`). `match_permutation` can take very long when no
  permutation exists: the auditor's search over wrong variants at rank 50 did not finish in 3.5 min and was stopped.
  A real mismatch could therefore hang instead of printing FAIL. Compare cheap invariants first, or add a node limit.
- **m4** `BrandtLevel.h:40` says "W_ell^2 = ell^n (checked)". At mixed level with N1 > 2 it is ℓ^n⟨ℓ⟩⁻¹, as the JSON
  records. W_ℓ is also not self-adjoint there (3 cells, recorded, not checked).
- **m5** `tests/brandtlevel_selftest.cpp:482-530`. At U₀ levels no committed check separates U_ℓ from W_ℓU_ℓW_ℓ⁻¹
  (same char-poly, both commute with everything tested); U vs U′ is tested only on the U₁(5^s) tower at k = 2. Add the
  relations U_q s0^* = s0^* T_q − s1^* and U_q s1^* = q^{k−1} s0^* to section D (they hold, §2 item 1).
- **m6** `plan/hacs/outbox/20261115T0655Z_HJ-4b.md:83` "so there is no ℤ-lattice": more exactly there is no ℚ-form of
  Sym^n; the odd-weight module is a vector space over a splitting field. Line 5 names the worker branch
  `impl/hacs-laneC-34`; the code is on `impl/hacs-laneC`.
