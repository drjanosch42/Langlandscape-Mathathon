## Checks

1. **Independence: OK.**
   - On the GL₂ side, T_ℓ comes from `module_Z` (`hacs_modz`), and the old-orbit a_q(g) and the residues of m come
     from HACS L_1 (`level_one_rational`, l.614). The U_q signs come from the `level_n` charpolys, and t_f(q) is
     computed from HACS a_q(g).
   - The S06 files are read only in `t5()`/`compare_row`, for the comparison fields. The oracle code is reused only
     as code: `congruence.defect`, `Character`, `_matching_ideals`.
   - One field is tautological, see m3.
2. **Local route: sound.**
   - R = ℤ[λ_v(gens) mod p^E] + p^E ℤ^r satisfies R⊗ℤ_p = ℤ_p[λ] + p^Eℤ_p^r. The check p^{E−1}ℤ^r ⊂ R
     (l.844–849) gives p^{E−1}ℤ_p^r ⊂ ℤ_p[λ] + p·p^{E−1}ℤ_p^r. By Nakayama, p^{E−1}ℤ_p^r ⊂ ℤ_p[λ], so
     R⊗ℤ_p = S_m exactly.
   - Precision loss is asserted (`padicprec ≥ E`, l.744), and every ord read is checked < E−1 (l.904).
   - Places whose residue field is F_{p^f} with f > 1 are skipped correctly: by Hensel their reduction is ḡ^e with
     deg ḡ > 1, so A has no F_p residue there.
   - If two places coincide mod p^E, the Nakayama check fails with `Refused`, so the error is loud.
   - Grouping by the residues of all generators gives exactly one maximal ideal per group (asserted at l.888).
   - I see no silent failure mode for the rank or for η.
3. **Ramified-place refusal: correct in principle.**
   - A place v ∤ m does not contribute to S_m, so it may be ignored.
   - The test p_ℓ(c₀) mod p against m's residues is the correct residue of T_ℓ at v when the Krylov coefficients are
     p-integral. When they are not, the code breaks out of the loop and leaves in_m = True, so it refuses.
   - The U_q residue is not compared, which errs on the side of refusing.
   - So the fix cannot accept a cell that it should refuse. There is a crash path, see m1.
   - (5,18,23)@40 is the cell this fix enabled, and it matches S06-C4 independently.
4. **a_q signs: OK.**
   - `u_d_split` divides out the Eisenstein and old parts exactly. With 2s ≢ 0 mod ℓ, the ± multiplicities are
     exact, and two ℓ must agree.
   - The JSON has `assignments_total = 1` in every computed cell, so the subset sum is unique even before projection.
   - Also, `_strip` compares components that include `a_q_sign`. Any second assignment would therefore make
     `sign_robust` false, so the rule is effectively "computed only if unique", which is conservative.
5. **Provenance: honest.**
   - The top level is 13bd624b (clean, 3966 s), and `spliced_rows` holds ['5,18,23'] with the full 28961d73 block
     (clean) and the reason. Both blocks have `hacs_sha256` a6acb500…4c9158, the version and `hz_settings`.
   - The code diff 13bd624b..28961d73 only relaxes the ramified refusal and adds the annotation and acceptance
     functions. So the six unspliced rows would be unchanged at 28961d73.
   - One stale line remains, see m4.
6. **Tests:** `python3 -m pytest -q tests/test_hacs_bridge_jl_defect.py` gives **8 passed in 8.59 s**. The HACS cell
   (13,12,31)@12 ran and was not skipped.

## Findings

- **m1 (minor, robustness)** `jl_defect.py:784` together with `:614`. `resid` has no `T{p}`, because `residues`
  excludes p, but `names` contains p when p ≤ 97 (for example (5,40,23) gives names ending in 23). If a ramified
  place matches m at every ℓ < p, the line `resid[f"T{l}"]` raises `KeyError`. That aborts the run: `t5()` catches
  only `Refused`. It is never silently wrong. Fix: iterate over `resid`'s keys, or skip `l == p`.
- **m2 (minor, overclaim)** `20261115T0832Z_HJ-8a.md:16` says "Two other routes are kept and tested against it".
  The tests compare only matrix closure vs abstract order (`test_abstract_hecke_matches_matrix_algebra_toy`). No test
  compares `_defects_local` with those routes, and no test exercises the ramified branch. The local route is
  exercised only through the HACS cell, against known values. Two cells rest on the local route alone, with no
  second route: (13,18,19)@36 and (13,12,31)@42. Either add a toy local-vs-global test or reword the note.
- **m3 (minor, tautology)** `jl_defect.py:1135`. `agrees_with_S06_C6` includes `vp_etaB`, `etaB_eq_eta_new` and
  `identity_with_etaB`. At weight k, `vp_etaB` is copied from `s06/T5_def.json`, the same S06-C5 source that C6 used,
  so that field is equal by construction. The independent fields are ord η, ord 𝔠, ord η_new and t_f(q), plus the
  native η^B cross-check. The note (l.38) should say which fields are independent. At shifted weight, η^B = (1)
  because the block has rank 1 (stated in D5). So "η = 𝔠·η^B" there adds no information beyond Thm E with
  η_new = 0, and the note could say so plainly.

  file also has native annotations, applied to all rows by the 28961d73 code at splice time. The `acceptance` block
  was also recomputed by that code. `native_definite_side` and `spliced_rows` are present, so nothing is hidden, but
  one line should say that the annotation and acceptance come from 28961d73.
- **m5 (minor, status words)** `jl_defect.py:12`, `:1152` (copied into `T5_hacs.json` `conventions.T_l`), and
