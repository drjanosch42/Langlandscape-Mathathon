# HJ-8-def: η^B natively, the definite side of the JL defect comparison (Lane C, worker C)

- **Branch:** `impl/hacs-laneC-7`, with laneC merged in at 5dfe8f6d.
- **Code:** b0dee376. Results and this note are in the next commit.
- **Status:** every number is *computed* (native C++). On the overlap it agrees with `s06/T5_def.json`.
- **Linked files:** none touched. There is one new standalone tool, `quat/tools/jl_eta_def.cpp`, and a collector, `hacs_bridge/laneC_hj8def_collect.py`. The tool links the quat library sources and NumberField (`IntPolyFactor`, `PureField`, `PolyAlg`, `Lll`, `Polred`) unchanged.

## Definitions (= defect/gram.py, S06-C5)

- **Module:** M = BrandtSym(C, n), the HJ-4a intrinsic lattice, equal to Sym^n(ℤ_p²) at p ≠ q. Level O^× of B_q.
- **Pairings:**
  - G_w = ⊕_x w_x⁻¹⟨,⟩_V, the **weight used**;
  - G_Γ = ⊕_x |Γ_x|⁻¹⟨,⟩_V, also reported.
- **Generic T:** T = Σ c_ℓ T_ℓ with ℓ ∈ {2,3,5,7,11}∖{q}, using gram.py's coefficient choices; χ is squarefree over ℚ.
- **Q_p-orbits φ:**
  - Factor χ over ℤ with `nf::factor_monic_over_z`.
  - Factor each ℚ-factor mod p (Cantor–Zassenhaus) and Hensel-lift the coprime splits.
  - When the generic T is not separating mod p (e > 1), separate inside the block by T + cT_ℓ, using Hensel on the block's characteristic polynomial.
  - If nothing separates, the result is reported as an unresolved union (`resolved_Qp_orbit = false`), for example a ramified orbit.
- **Values:** A_φ = ker φ(T), saturated mod p^R (R = 40), and **v_p(η^B) = v_p det(G_w|A_φ)**. For deg φ > 1 this is the length of the congruence module (Hsieh, Rem. 7.3).
- **m (blocks):** a block is a residual eigensystem of every T_ℓ, given by the irreducible residual factors. old_congruent compares it with the level-one form g, computed exactly from E₄, E₆ and Δ (dim S_k(1) = 1 only), and v_p(a_q(g)² − q^{k−2}(q+1)²) is recorded.

## Deviations

1. Q_p-orbits are computed by ℚ-factorisation, Hensel and separation, not by PARI `factorpadic`. Unsplit unions are flagged.
2. One weight-k+(p−1) cell is skipped for cost. At the other six, η^B is obtained by the ring-theoretic route (rank-1 M_m), and the Gram values have no η^B meaning, because the pairing is not perfect.
3. The census skips a cell as trivial when χ mod p is squarefree and no level raising is possible. In that case every m is a single orbit with η^B = 1, because the blocks are orthogonal summands and G_w is perfect.
