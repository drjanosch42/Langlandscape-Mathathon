## 1. What was built

`code/hacs/src/hacs/Registry/JL/quat/BrandtLevel.{h,cpp}`, with conventions (B1)–(B8) in the header.

**The module.**
- M_Z(U) = ⊕_{cells y} Λ_c^{Stab_y} for U = U₁(N1) ∩ U₀(N0).
- Cells come from `LevelSet` (HJ-3); the lattices Λ_c, ρ_n and the splitting come from `BrandtSym` (HJ-4a).
- It is the Gross form at level: Φ(Lα, dα) = ρ_n(α)⁻¹Φ(L, d), where U acts trivially on V.
- The lattice is the intrinsic one of HJ-4a (C5), on each cell. So at every p ∤ D it is again the stage-01 seed lattice.
  This covers the stretch item at level too.

**One uniform rule for all operators (B2).** Every operator is a sum of terms ρ_n(g)Φ(I_{c′}, d·g). The datum moves by
right multiplication with the same element g = conj(μ)/N_c. Writing d·g = d_{y′}γ, the term is ρ_n(gγ⁻¹)Φ(y′).

**Operators.**
- T_ℓ for ℓ ∤ DN: all ℓ+1 neighbours.
- **U_ℓ for ℓ | N — classical (B3), stated for the re-audit.**
  - Definition: U_ℓF(x) = Σ_{j<ℓ} F(x·ι_ℓ⁻¹[[ℓ, j], [0, 1]]), with **no p^{k/2−1} (or p^{−n/2}) normalisation**.
  - It is the seed's N_{U_p}, via f = x_p⁻¹F (rem:s01-dictionary).
  - In ideal terms it takes the ℓ neighbours for which the transported datum stays primitive (U₁) or stays a line (U₀).
    The code asserts that exactly ℓ survive.
  - Cross-check: the U_ℓ char-polys equal PARI's classical a_ℓ data on 63 U₀(M) cells (§2).
- U′_p = [U diag(1,p) U]: the neighbour of the datum line, with data ((v − p^s j w)g/p, dg).
- ⟨d⟩ (adelic: v ↦ d⁻¹v).
- Π_p, Π_D, unnormalised.
- W_ℓ for ℓ ∥ N0: J = the neighbour of the line, and the new line = e·L·g.

**Level maps.** `pullback` (π^*, also s0^*), `trace` (N1 refinements), and `degeneracy_s1` (s1^*F(x) = F(xϖ_q)).

**Pairing.** ⟨,⟩_w = Σ N_c^n β_n / w_y, with `adjoint`.

**`Level` additions.**
- `LevelSet::locate_unit` returns the cell and the unit γ with point = rep·γ.
- `reduce_point`.
- `locate` now rejects non-primitive vectors and zero lines.

Self-test: `quat/tests/brandtlevel_selftest.cpp`, which writes `code/results/laneC/hj4b_level.json`. The PARI script is
`code/python/langlandscape/hacs_bridge/laneC/check_hj4b_mf.py`, which writes `hj4b_level_mfcheck.json`.

## 3. API for worker C (HJ-7b: exact integral Ihara cokernel at weight k)

```cpp
#include "BrandtLevel.h"
MaxOrder O(D); ClassSet C(O); BrandtSym M(C, k - 2); LevelModel Mo(C, q);
LevelSet Xs(Mo, {1, 1}), Es(Mo, {1, q});         // vertices = O^x classes, edges = O_0(q) classes (cells)
BrandtLevel X(M, Xs), E(M, Es);
ZMat s0 = BrandtLevel::pullback(E, X);           // rank(E) x rank(X): Phi -> Phi o s0  (forget the q-line)
ZMat s1 = BrandtLevel::degeneracy_s1(E, X, q);   // rank(E) x rank(X): Phi -> F(x varpi_q) = rho_n(g) Phi(I_c', d g)
ZMat Tq = X.T(q), Uq = E.T(q), Wq = E.W(q);      // T_q = s0^dagger s1 (checked); U_q classical; W_q^2 = q^n
QMat G = E.gram();                                // <,>_w on M(O_0(q)); E.adjoint(A) = G^-1 A^T G
E.cells()[y]: c_enum, c_mod, Zinv / EK (the invariant basis), B (N_c^n beta_n); E.offset(y)
```
- The edge coefficient system is ρ_n on Λ_c^{Stab_e}, with the stabiliser of the O₀(q) cell.
- It is the same intrinsic lattice as the vertices, so the weight-k Ihara map ι = (s0^*, −s1^*) is integral by construction. The functions return s0^* and s1^*; the consumer applies the minus sign (TreeK.h convention).
- Columns follow the convention of (B8).
- Matrices act on functions. The homological (divisor-side) maps are the ⟨,⟩-adjoints.

## 4. Deviations (disclosed)

1. **Odd k is not supported.** For n odd, Sym^n has no ℚ-form for a ramified B: the odd-weight module is a vector space over a splitting field (e.g. K = ℚ(√a)), not over ℚ, so there is no ℤ-lattice in our sense; the code throws.
   S_k(Γ₁(N)) at odd k would need ℤ_p- or O_K-coefficients through ι_p. This is open, and none of the accept files needs it.
2. **U₁(N) is not compared with PARI** (that would need character-by-character Γ₁ newspaces). U₁ is covered by up.json at
   k = 2 (matrices equal up to permutation) and by the relations and adjoints in §2.
3. U_ℓ for ℓ² | M (M = 4) is in the commutation checks but not in the PARI U_ℓ comparison, whose old-form formula is for
   ℓ ∥ M.
4. **U′_p needs the level model modulo p·N1.** The `LevelModel` modulus must be divisible by p·N1; this is checked and
   throws otherwise.
5. The HACS `def:cosetrepsN` alignment of HJ-3 deviation 1 is unchanged.
