## 1. Definitions vs v6 Task 2(b)/(c)

**Task 2(b): the right object.**
- `hacs_request_v6.txt:41` asks for the "torsion of the S1b Mayer–Vietoris sequence (quaternionic Ihara cokernel)". README.md:52 describes it as the cokernel of α from two copies of the level-1 Brandt module to the Eichler level-ℓ module, on the tree of the amalgam prime.
- The code computes exactly this, with the tree prime written q: coker(ι = (s₀\*, −s₁\*) : M(O;V_k)² → M(O₀(q);V_k)) (`jl_tree_k.cpp:175-222`, the coboundary at `TreeK.cpp:462-470`).
- In the definite case the vertex groups are finite of order prime to ℓ ≥ 5. The MV sequence therefore reduces to H⁰ = ker ι and H¹ = coker ι, and the higher terms vanish. So the cokernel carries all of the torsion that Task 2(b) asks for.
- The sign follows amalgam.py's α(x,y) = dg₁x − dg_q y.

**Task 2(c): W_D is the right W, so the deliverable is not missing.**
- The request asks for "W_p (p | D)" (`hacs_request_v6.txt:42`; README.md:53).
- For prime D this is W_D at the ramified prime, not W_q at the tree prime. The code computes W_D = Π_D/D^{(k−2)/2} on BrandtSym's M_Z (`jl_tree_k.cpp:317-357`).
- The ω(D) = 3 case (D = 30) was optional in the request ("if S1 reaches it"). It is listed as an open item (note l. 102).

## 2. Independence

- **`jl_tree_k` reads no files.** It has no ifstream for input and no Python results; its case lists are hard-coded.
- **The compare script recomputes nothing native.** `laneC_hj7k_compare.py` takes the binary's output, the s02/s03 reference files and PARI `mfdim([Dq,k],0)`, which is the new space and is independent.
- **No compared field is tautological.** Echo fields are excluded from the substantive counts (l. 39-48).
- **BrandtSym cross-check.**
  - The ranks agree, but the evidence is weak: both sides compute Σ dim V^{Γ_c}, though through different code.
  - The charpoly(T_q) comparison is substantive. Global splitting with the C5 lattice (BrandtSym) and local frames with tree transports (TreeK) are independent constructions.
- **The NEW values had no oracle, so I added two independent checks** (scratch only, nothing committed):
  - **Ihara cokernel vs `twoterm.LocalModel`: 11/11 cells agree.**
    - The Python side has its own S01 splitting. It gives `Hco1` mod ℓ³, compared on free rank and ℓ-torsion.
    - The cells (D,q,k,ℓ) were (2,3,8,5), (3,2,10,7), (5,2,14,11), (7,3,14,5), (5,3,10,7) and (7,2,8,5), which have Z/ℓ, and (2,5,12,13), (13,2,6,7), (11,2,4,5), (3,7,8,11) and (2,11,14,17), which have none.
  - **W_D vs the PARI Atkin–Lehner eigenvalue: 38/38 cells agree.**
    - The relation tested is tr W_D = [k=2] − tr(w_D | S_k(D)^new), with rank = dim S_k(D)^new + [k=2], using `mfatkininit`.
    - This is consistent with a_D = −ε_D D^{(k−2)/2}. I suggest adding it to the compare script (m6).

## 3. Torsion statement

- **The WP note is properly qualified.** Note l. 60 reads "no torsion at any prime k < l ≤ 2000 with l ∤ 6Dq". Deviation 2 and the open items say it is a scan and not an exact Smith form.
- **Each scanned prime is decided exactly.** ι is a matrix over Z_(ℓ) on e_H Sym^n(Z_ℓ²) = (Sym^n)^H, so a rank drop mod ℓ happens exactly when there is ℓ-torsion.
  - The reference rank rq (mod 1000003) is pinned by the independent mfdim match in 210/210 cells. If rq were too small, the free rank would not match.
  - In every torsion entry `all_divisors_below_l^m` is true.
- **But the JSON drops the exclusion; see m1.**

## 4. The interim Sym^n action in TreeK

- **The ρ_n column convention matches.** `SymCoeff::act` (`TreeK.cpp:132-155`) has column t equal to the coefficients of (aX+cY)^{n−t}(bX+dY)^t, indexed by the power of Y. This is BrandtSym.h (C2), l. 17-21, and twoterm.sym, character for character.
- **The transport is consistent.** u₀ = φ_c(γ₀) and u₁ = ι(a_{c′}γ̄₁μā_c)/(N_{c′}²N_c·q·na_c) (`TreeK.cpp:276-281`); this is μ/(qN_{c′}) as in HJ-7a's reviewed EdgeMove. `conj_ok` is true in all cells. The pullback is u_j⁻¹f, and `coords` throws if the vector leaves V^{H_e}.
- **The |Γ_x| weights are consistent.** H = φ(Γ_x) includes −1. The cohomological traces use [H_x:H_e] = |H_x|/|H_e|, which is the same ratio with or without ±1. The projector e_H divides by |H|, a unit for ℓ ≥ 5. All of this is consistent with BrandtSym's γ (including −1) and w = γ/2. The Ihara map itself uses only pullbacks, so it carries no weights.
- **The empirical confirmation is strong.** charpoly(T_q) equals BrandtSym's with no q-power rescaling (j = 0) in 190/190 cells, and the s02/s03 values agree 276/276.
