## 2. HJ-12a items

**1. U_p normalisation — OK (as far as HJ-4a reaches).** HJ-4a has level O^× only, so there is no U_p yet. T_ℓ is
`Σ_J ρ_n(conj(δ_J)/N_c) = Σ_J ℓ^n ρ_n(β_J^{-1})`, the same formula as `symn.py`. It matches PARI's classical
`mfheckemat` for every ℓ < 20, so there is no ℓ^{k/2−1} factor. Derived: def:s01-hecke has
`(T_g f)(x) = Σ g_{i,p}·f(x g_i)`; under F(x) = x_p f(x) this is `(T F)(x) = Σ F(x g_i)`, also at ℓ = p. The U_p
normalisation itself must be audited again on HJ-4b.

**2. Π sign, U_ℓ ↦ +Π_ℓ — OK.** `terms_Pi` uses J = P_p I_c and g = conj(δ)/N_c = p·β^{-1}, which is `pi_ell.py`'s
`ℓ^n β^{-1} Φ(L_{c'})`. P_p = D·O^# + pO is the two-sided prime (index p² is checked in code). Π² = p^n is unnormalised.
Independent check by this audit (computed): `charpoly_Pi_D` of `hj4_symn.json` equals
`charpoly(mfheckemat(mfinit([D,k],0), D))·(x−1)^{[k=2]}` on all 32 prime-D cells of rank > 0 (D ≤ 13, k ≤ 12). So the
Π_D-eigenvalue is +a_D with no extra power of D. The self-test's own pi_sign comparison is against the Python Brandt side
of `pi_sign.json`; that JSON's `mf` side agrees with it apart from the Eisenstein line at k = 2.

**3. w_x vs |Γ_x| — OK.** Both are delivered and `<,>_w = 2<,>_Γ` exactly. Derived: with Nrd x = r_x u_x and
N_c = r_x^{-1}, `u_{x,p}^n β_n(f,h) = N_c^n β_n(F,H)`. So `Σ_c N_c^n β_n / w_c` is exactly def:s01-pairingV, including its
unit factor. T_ℓ and Π are self-adjoint for it (rerun).

**4. Cohomological vs homological; ρ_n column convention — OK.** The module is the function side: Γ_c-invariants, and
F(γxu) = s(γ)F(x) gives f(γxu) = u_p^{-1} f(x) for f = x_p^{-1}F. `rho_K` builds column t from
(s00·X + s10·Y)^{n−t}(s01·X + s11·Y)^t, which is eq:s01-Vk, with no transpose or inverse. Matrices are in column
convention, and at k = 2 the row sums are ℓ+1 (constants are fixed), equal to Brandt2's `brandt_neighbours`. A consumer
that wants the homological ℤ[X] operator must take the adjoint; see m5.

**5. The lattice — sound.**
- *Independent of the representative:* derived. ρ(α^{-1})∏Q_{x_i} = nrd(α)^{-m}∏Q_{α^{-1}x_iα}, and
  (O_r(Lα)^0)^# = α^{-1}(O_r(L)^0)^#α, so ρ(α^{-1})Λ(L) = Λ(Lα). Test H confirms it with unimodular base changes.
- *Equal to the seed lattice at p ∤ D, p = 2 included:* derived. Locally Λ^ι(L)_p = (N(L)·nrd x_p)^{-m} ρ_n(x_p) Sym^n(ℤ_p²),
  and N(L)·nrd(x_p) is a p-unit, so F(x) ∈ Λ exactly when f(x) ∈ Sym^n(ℤ_p²) (the polynomial lattice of eq:s01-Vk).
  At p = 2 the XY-coefficient 2α runs through ℤ_2. Independent check by this audit (computed, 80 class lattices,
  D ∈ {2,3,5,7,11,13,17,23,30,42}, n = 2..10): every Λ_c is O_r(I_c)-stable and
  det(N_c^n β_n | Λ_c) = ±∏_i binom(n,i)^{-1} · ∏_{p|D} p^{-n²/2}. Away from D this is the determinant of Sym^n(ℤ_p²), for
  every class and at p = 2, 3.
- *T_ℓ integral:* derived termwise (ℓ·O_c ⊂ O_r(J), then duality); the code throws on any non-integral term, and no
  throw occurs in the full run.
- *"Congruence modules and Gram determinants at p ∤ D are invariants":* correct, read as p-parts and p-adic valuations
  (determinants up to p-adic units). It refers to the polynomial lattice, which is not self-dual for p ≤ n, as stage 01
  already says.

**6. Independence of the char_ℤ comparisons — no tautology found.** `symn.json`'s `rhs` is computed by PARI in
`symn.py` (line 567), not by the Python Brandt code. `check_hj4_mf.py` calls PARI live on the native char-polys. Char-polys
cannot see a transpose or a lattice change; those are covered by the row sums at k = 2, the integrality throws, test H
and the determinant check above. Of the 374 operators, 110 repeat the symn.json comparison (same PARI source), so 264
are new.
