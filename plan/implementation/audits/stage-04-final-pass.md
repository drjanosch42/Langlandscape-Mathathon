### ribet_exact: precise statement

* Generality: `(R : Type*) [CommRing R]`, any ring (so `R = ℤ_[p]` instantiates directly; `ribet_exact_baseChange` does not exist and is not needed).
* Hypotheses: `hU : Tree.IsQLevel d q hq U` and `hc : Tree.BGConnected d q hq U hU` (explicit; `d q hq U` implicit; `[Fact q.Prime]`). No `IsQAdmissible` and no SA/HS in the plain version; there is a `…_of_SA_HS` version of the same lemmas.
