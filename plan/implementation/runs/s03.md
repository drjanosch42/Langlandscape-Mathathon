## Lessons

1. Single-WP jobs and a two-node, always-two-jobs regime gave feedback in 2-3 min per round; 22 rounds in 52 min. Keep it.
2. A stale-base job wastes a round: L4 and L7 were "not assessable" because the L1 fix was missing. Every job must contain all upstream fixes (use ⊇ chains: int2 ⊇ int1b).
3. Writers must run the frozen-tree guard locally: bad import path (L10), missing `noncomputable`, `Nonempty.casesOn` into data, `DecidableEq`. A cheap pre-check of module names against the frozen Mathlib would have saved 4 rounds.
4. Propositionally equal subgroups/levels (`rightConj U0q alpha` vs `s1Level`) hit L10b and L14 twice; plan transport equivalences in the signature.
5. Escalate to opus after 2 failing sonnet rounds, not 5 (L8, L9); and start a rescue writer when a hard WP is at round 3 (L2 cost 5 rounds).
6. Branches stacked on an integration tree must be cut from wip-implementation, otherwise cherry-picks are needed (L6, L8).
7. The brief must say "worktree only; stop if absent" from the first minute (incident); and the licence header rule belongs into the first brief.
8. Run the Fable L12 audit in parallel with the last two WPs and diff the tree afterwards: it saved the planned 10 min and the diff check was cheap.
