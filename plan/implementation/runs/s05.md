## Lessons (final candidates)

1. **Skeleton quality gates the whole core:** the L1 skeleton lacked an import and had two proof errors; L2, L3, L5, L2b, L7 were blocked for 3 rounds. Compile-check skeletons at the skeleton commit (one-file job) before stacking dependants.
2. **Scratch rounds on a sorry'd upstream (int1e) bring nothing when the fix lands within one round time;** only worth it if the upstream fix takes more than one round.
3. **The early full-tree gate (pregate) pays off:** it took G1 off the critical path (G1 round 6 min) and exposed the missing test modules (-> LT); repeat whenever one WP is still open.
4. **Sonnet draft + one opus fix is the efficient pair for Lean "mechanical with meaning" too** (E5': 16.8 vs 27.5 min active, quality comparable); the prior for Lean-hard (S04) and this cell now agree.
5. **A production rescue writer for the experiment WP was insurance that was not needed** (strand B first green, production green 90 s later and discarded); start it only if the first strand round is red by a margin.
6. **Fix the merge rule up front** (S04 argument avoided); here merged = winner, but the rule held regardless.
7. **Part-wise Fable Lean audit with in-stage fixes** (L11a/b/c) again moved fixes before the final gate; part 3 after G1 is the cost: L4g/L11c add a post-G1 stack, so run the last audit part before G1 or budget the extra round.
8. **Stack the dependent WP on the writer's draft** (L11c on the L4g draft): int4b already validated L4g and exposed L11c's errors in the same round; one more round green. Also, trivial mechanical fixes (L11c zero arms, `TensorProduct.induction_on` has no `zero` arm) are cheaper by the stage master than a writer round; heartbeat/`whnf` timeouts (L4g) are one opus fix.
9. **Deprecated or version-dependent eliminators recur in drafts written without a build** (E5' B-1 `rw`/`simpa`, D-1 unknown constants, L11c zero arms, `push_neg`, `haveI`): add them to the test-file pre-check list (S04 pre-check 7).
10. **Process hygiene:** (a) never push `HEAD:` from a shared worktree; push by explicit ref, check the branch first, keep integration in a scratch worktree (incident 00:19Z); (b) outbox file names are not reliable times: take times from commits and inbox files, or stamp the real time at creation.
