## Lessons

1. **Test-file scope errors cost four extra rounds** (L5 `hM hpM`, L9 `hp`, L12 21 unqualified `Langlandscape.Tree` names, L10b test timeout; also L6 strands and L14a): the library went green one round earlier than the test file each time. Writers must build the test module locally (or compile-check names/binders) before the push; the Lean brief got pre-checks 7 (tests) and 8 (2c7125c6).
2. **BG / ZX definitional unfolding (`whnf` heartbeat timeouts)** blocked L12 (16 -> 4 -> 0 errors) and L13b (`transA_surjective_of_snake`, dropped). Never unfold `BG`, `ZX`, `ordPart` in a rewrite or `exact`; build bridges through explicit generic lemmas on `Submodule`s (L12 round 2, e7dae9c) and keep the optional theorem optional (deviation 7).
3. **Submodule-of-submodule elaboration and `HasQuotient` on `↥submodule`** (L4 `ordPart_ker_deg`, L10 rounds 3-4: `ordControlEquiv` dropped): state such lemmas for a generic `Submodule`/restriction first and avoid quotients of coerced submodules; this is cheaper than repeated Opus fixes (L4 needed 4 fix rounds, L10 5).
4. **Experiments must not block the critical path:** both E1' strands were red after round 1 while L9/L10/L12 waited on L6; the production rescue writer (deviation 1) and the early merge of the opus head (deviation 5) were needed, so production rescue/merge is not the experiment winner. Decide and record the "merged != winner" rule in the strand brief up front (precedent S02-E1).
5. **`#min_imports` output needs the hand check:** the min-imports merge broke `Ribet.Mazur` (Tactic import lost from MazurArith) and S04-IMP dropped a PadicDecomp import; both were found only by a full-root build, not by the per-file build. Run the full root build for every import-only change.
6. **Header/licence churn mid-stage** (GPL -> Apache -> Mathlib header, module layout, public/private imports, import hold then gate) forced a 117-file conversion round (13.7 min of queue on TITAN) and rewrote merged files twice; freeze the Lean conventions at stage launch and put them in the first brief.
7. **Delayed teammate messages vs the file outbox:** cross-node messages (Abhijit) arrived while jobs were running (min-imports hold at 22:07Z, then the gate at 22:21Z); the file outbox and merge notes remained the authoritative record. State the hold/gate rule in the outbox note and act on files, not on message order.
8. **Two-node parallel lettered rounds worked again** (49 rows in 112 min; typical result in 2-4 min), but the speculative superset job (int6-1, 22:24Z) mostly returned "blocked" and TITAN queue waits reached 12-13 min behind full header/rebuild jobs (int3b, int5-1, mod-1). Do not queue a speculative superset behind a rebuild; send single-WP fix jobs to the free node.
9. **Escalation rule worked:** L4 and L14a went to an Opus fixer after 2 resp. 2 sonnet rounds (S03 lesson 5 applied); L4 still needed 4 fix rounds (elaboration errors), so rescue writers for hard WPs (L4, L6, L12) were started at round 2-3 and stopped when the original went green: cheap insurance, never decisive.
10. **Gate-1 earlier than planned, with the audit in parts** (gate-1 at t = 113 vs planned ~ 120-125; L16 parts 1/2a ran while L10/L13b were open) moved most audit fixes (L17a/b) inside the stage; the final tail was only L17c + the final gate (14 min after gate-1).
