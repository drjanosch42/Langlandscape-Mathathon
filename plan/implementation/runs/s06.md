## Lessons (final candidates)

1. **`⧸` vs `≃ₐ` precedence (lean.md candidate):** `A ⧸ J ≃ₐ[R] B` parses as `A ⧸ (J ≃ₐ[R] B)`; always write `(A ⧸ J) ≃ₐ[R] B`. `→ₐ` is unaffected (int2e-1, `quotient_baseChange`; two rounds).
2. **`congruenceIdeal` on a quotient-sourced `AlgHom` needs both implicits pinned** (`(A := …) (S := … ⧸ …)`) when there is no expected type: three rounds (int3a, int3b, int3e: lines 46:30, 46:39, 45:67) on the same cause. After the first error, grep for every occurrence of the function applied to `lam'`/`lam'k` and fix them all at once, not one by one.
3. **Module conversion drops transitive imports** (`TwoByTwo`: `Ideal.Span` came via a non-module file); after converting, re-derive the import list of every file, not only the headers.
4. **`include D in` does not give dot-notation for derived declarations:** make `(D : Setting …)` explicit (int2b-1, 27 errors in one file; one fix).
