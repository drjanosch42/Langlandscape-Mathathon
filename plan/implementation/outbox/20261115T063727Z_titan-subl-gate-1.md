## subl-clean-1 (TITAN; CLEAN ROOM — Fabian-authorized one-off exception to agents/rules/frozen.md)
Purpose: the official check builds a FRESH clone with plain Lake. This job must not touch the frozen Mathlib tree, the
dependency farm, any existing checkout or `~/.cache/mathlib` of the frozen setup. Everything lives under a throwaway dir X.
```
X=$(mktemp -d /tmp/subl-clean.XXXXXX); cd "$X"
export XDG_CACHE_HOME="$X/xdg-cache" MATHLIB_CACHE_DIR="$X/mathlib-cache"   # keep the Mathlib cache inside X
unset LAKE_PKG_URL_MAP LEAN_PATH
git clone --branch impl/submission-lean file://<TITAN's existing clone path> repo   # or https://github.com/drjanosch42/Langlandscape once public
cd repo && git checkout <SHA> && cd lean/Langlandscape
test ! -e .lake && test ! -e ../trace-formula-project-import/lean/.lake            # truly fresh
/usr/bin/time -v lake exe cache get   > "$X/cache.log" 2>&1; echo "cache rc=$?"
/usr/bin/time -v lake build            > "$X/build.log" 2>&1; echo "build rc=$?"
/usr/bin/time -v lake build AlgJL      > "$X/algjl.log" 2>&1; echo "algjl rc=$?"        # GL2TF import fully (AlgJL default target)
/usr/bin/time -v lake build LanglandscapeTests LanglandscapeVendorStacks > "$X/tests.log" 2>&1; echo "tests rc=$?"
lake env lean Audit/PrintAxioms.lean   > "$X/axioms.log" 2>&1; echo "axioms rc=$?"
```
(Run under the node's usual memory cap / `systemd-run --user --scope -p MemoryMax=…` if that is the TITAN norm; elan must
already have `leanprover/lean4:v4.35.0`, otherwise elan downloads it — note it.)
- Report: rc and wall time of each step; peak RSS; job counts; warnings count (`grep -c '^warning'`) per log; the
  PrintAxioms count (expected 950, non-standard 0); `ls .lake/packages` (expected: mathlib plausible LeanSearchClient
  importGraph proofwidgets aesop Qq batteries Cli — nothing else); evidence that the only network fetches were the git
  clones of those packages and the Mathlib cache download (`grep -iE 'cloning|downloading|fetch' cache.log build.log`);
  that `lake-manifest.json` and `lakefile.toml` are unchanged afterwards (`git status --porcelain` empty apart from ignored
  files); and the time spent building `AlgJL.*` (`grep -c 'Built AlgJL' build.log` + its share of the wall time).
- Afterwards `rm -rf "$X"` (it contains no symlink into any frozen tree).
