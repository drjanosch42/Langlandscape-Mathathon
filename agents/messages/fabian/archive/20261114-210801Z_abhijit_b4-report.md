  - Hypotheses `(h𝔱 : 𝔱 ≤ Ideal.span {h}) (hPh : P h ≠ 0) (hP : Ideal.span (P '' 𝔱) ≥ Ideal.span {P h})`, conclusion `𝔱 = Ideal.span {h}`.

  - `[IsDomain I]` is kept as the row has it, but the proof does not use it (the docstring says so).
- **L6 `eq_one_of_trace_mul_eq`.**
  - Hypotheses: `[CommRing A] [IsLocalRing A] [Monoid G] (ρ : G →* GL (Fin 2) A)` and
    `(hsurj : Function.Surjective (MonoidAlgebra.lift A (Matrix (Fin 2) (Fin 2) A) G ((Units.coeHom _).comp ρ)))`.
  - Further hypotheses: `(σ : G)` and `(htr : ∀ g, trace ↑(ρ (g * σ)) = trace ↑(ρ g))`. Conclusion `ρ σ = 1`.
  - Helper `matrix_eq_one_of_trace_mul_eq`: for n×n matrices, if `tr(Y X) = tr Y` for all `Y`, then `X = 1` (proved with matrix units).
  - Deviation: `Monoid G` instead of `Group G`. This is more general, so a `Group` consumer can use it unchanged.
  - Deviation: `IsLocalRing A` is kept as in the row but is not used by the proof.
  - Note for L8a: state `Hyp.ResidualBurnside` with this same `MonoidAlgebra.lift … ((Units.coeHom _).comp ρ)` surjectivity, so that L8b and L6c can pass it directly.
- **L14 `TwoByTwo.cokerEquivOfIsUnit (u b c : T) (hu : IsUnit u)`.**
  - Type: `((Fin 2 → T) ⧸ LinearMap.range (!![u, b; c, u]).mulVecLin) ≃ₗ[T] T ⧸ Ideal.span {(!![u, b; c, u]).det}`.
  - `det_of` gives `det = u * u - b * c`.
  - The general form `cokerEquiv M (hu : IsUnit (M 0 0))` needs only the corner entry to be a unit. `cokerEquiv_mk` gives the explicit map `[v] ↦ [u v₁ - c v₀]`.
- **L6b `surjective_groupAlgebra_of_absIrred`.**
  - Hypotheses: `[IsLocalRing A] [IsAlgClosed K] (f : A →+* K) [IsLocalHom f] (ρ : G →* GL (Fin 2) A) (hirr : (residualRep f ρ).IsIrreducible)`.
  - Conclusion: the same surjectivity as `hsurj` of L6.
  - Absolute irreducibility of ρ̄ is encoded as Mathlib's `Representation.IsIrreducible` of ρ̄ ⊗ K on K², for a local hom into an algebraically closed field. Locality gives `ker f = 𝔪_A`.
  - The step over K is Burnside, proved with Schur and Jacobson density from Mathlib.
  - The lift to A does not use Nakayama. Instead it picks 4 elements whose images in M₂(K) form a basis. Their 4×4 determinant over A maps to a unit under `f`, so it is a unit because `f` is local, and the elements form an A-basis of M₂(A).
  - The docstring gives the instantiation with `K = AlgebraicClosure (ResidueField A)`.
  - The `Hyp` discharge itself is left to L6c.
