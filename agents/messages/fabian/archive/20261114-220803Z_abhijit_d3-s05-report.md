### Item 1: new `lem:s05-Up-pullback` (sign.tex)
**Statement.** Let the Picard U_p be `a_*b^*` on the U_p-correspondence curve of quadruples (E, ι, C, D) with D ∩ ι(μ_p) = 0, where a forgets D and b is the quotient by D. This is the RS §2.3.1.1 pp.28–29 recipe for T_p, and Conrad's Def 5.5 p.68 with Γ_1(N,p) from pp.64–65. Then for s' ≥ s ≥ 1:
- (a) `π^* U_p = U_p π^*` on J_s → J_{s'};
- (b) β_{s's} commutes with U_p on X_q;
- (c) the Albanese U_p commutes with `π_*` instead.

The same holds in the naive model.

**Proof.** The a-square (Y_{s'} → Y_s over π) is cartesian on the open curves. This follows from rigidity, using s ≥ 1, so that ι'(μ_p) = ι(μ_p), and N_s ≥ p ≥ 5, so the moduli problem is representable. Base change then holds on divisors supported away from the cusps, and passes to J by moving divisors. (b) follows by the Néron mapping property and contravariance of X_q.

**What it replaces.** The old forcing step was the forms argument with coset representatives (1 j; 0 p). That argument is about forms and the inclusion of forms, and has been replaced.

**Literature.** As D4 found, no source states the pullback compatibility.

**Residual caveats (not smoothed over):**
- (d) is a statement about the shape of HypX: among θ and θ^Ros, (X1)–(X3) force θ. HypX itself stays a hypothesis.
- The argument needs rk e Z_p[S_s] ≥ 2 at some s ≥ 1. Since the rank is r_Λ p^{s−1} (stage-04 control, proved modulo cited), this holds whenever r_Λ ≥ 1. If r_Λ = 0, θ and θ^Ros are not separated.
- T05-2 stays a numerical validation.

### Item 2: new `lem:s05-models` (sign.tex)
**The map.** φ: X^μ_s → X^nv_s over Q is (E, ι, C) ↦ (E/ι(μ_N), ψ(x), ψ(C)) with e_N(ι(ζ), x) = ζ. It is an isomorphism because, over C, it is Conrad's w_ζ (p.64), which satisfies w_ζ^{-1} = w_ζ (p.68).

**Intertwining:**
- U^μ_q φ^* = φ^* U^nv_q ⟨q⟩_nv^{-1};
- ⟨d⟩_μ φ^* = φ^* ⟨d⟩_nv^{-1}.

The U_q identity uses the Weil-pairing factor e(χu, χv) = e(u, v)^q.

**Deduction of the rows:**
- Transporting row 1 gives Frob_q = q⟨q⟩^{-1}U_q (row 3) and σ_q = ⟨q⟩U_q^{-1}.
- σ_q = U_q needs U_q² = ⟨q⟩ on X_q ⊗ Q, as elsewhere in the table.
- Row 2 then follows from row 3 by the change of functoriality, as row 4 follows from row 1.

**Stated assumption.** Row 1 (RS L.3.17) is read with U_q = this a_*b^* recipe. RS define the correspondence only for T_p with p ∤ N, so this is a convention we adopt, not a citation.

Diamond–Im (8.4.1) p.73 is kept as a consistency remark only.
