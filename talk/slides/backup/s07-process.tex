  \textbf{Architecture}
  \begin{itemize}
    \item One global master (Opus) delegates everything: stage masters, track coordinators, workers (Haiku/Sonnet/Opus).
    \item Lean builds on two remote nodes (TITAN, CONCEPTD); Abhijit's node (separate account) takes work packages over a git message channel.
    \item Every stage: WPs on worktrees, batched integration rounds, Fable Lean and chapter audits in parallel, a from-scratch final gate.
    \item Model policy set by a paired-strand study with blind Fable audits (\texttt{agents/rules/model-selection.md}).
  \end{itemize}
  \end{column}
