\begin{frame}{HACS: beyond Mazur, two implementations, honest timing}
  \footnotesize
  \begin{itemize}
    \item \textbf{$k>2$} ($60$ integral $\mathrm{Sym}^n$ cells, $26$ of positive rank; the lane closure counts $32$): one cusp--cusp congruence beyond Mazur, at $D=13$, $k=8$: $|C|=37$,
      between the orbits $(x-10)$ and $(x^2+19x+6)$, both with $w_{13}=-1$. GL$_2$ side:
      $\operatorname{Res}_{\mathbb Z}(x-10,\,x^2+19x+6)=296=2^3\cdot 37$, and $37$ divides no other resultant of $T_2$-factors at $(13,8)$
      (consistent, not a confirmation). At $k>2$ the lattice is not canonical.
    \item Ring module $(T_f\times T_f^c)/T$ (lattice-independent; depends on the operator list): primes at $k>2$ in $\{2,3,D\}$,
      plus $7$ at $(13,12)$ and $37$ at $(13,8)$; at $k=2$: the Mazur primes.
    \item \textbf{Two independent exact implementations} (HACS-native C++; Python $+$ PARI) agree on all $69$ orbit modules and on Mazur $14/14$.
      Reading is milliseconds in both: no read-side speed claim.
    \item \textbf{Build side, the one speed line:} class set $+\,T_2$ for $B_{997,\infty}$ ($h=83$), single-threaded, same node:
      Python $64.7$\,s vs native HACS-JL core $0.02$\,s (a factor of about $3\times10^3$; ``$\sim10^3\times$'' is the honest statement, not an exact factor;
      a first measurement on a loaded node gave $61$\,s vs $0.025$\,s).
    \item Native census: all $404$ primes $q\le 2777$ generated in $19.6$\,min; Eichler's class-number formula holds for all $1229$ primes $D<10^4$.
  \end{itemize}
