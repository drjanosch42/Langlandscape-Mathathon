A \emph{geometric class} is a pair $(t,d)\in\Q\times\Q^\times$, identified with the monic polynomial $X^2-tX+d\in\Q[X]$. The
\emph{class} of $\gamma\in\GL_2(\Q)$ is $(\tr\gamma,\det\gamma)$, i.e.\ its characteristic polynomial $P_\gamma$. For a class $\mathcal O=(t,d)$ we write
also $\mathcal O$ for its fibre
\[
  \mathcal O=\{\gamma\in\GL_2(\Q):\tr\gamma=t,\ \det\gamma=d\},
\]
and $\mathcal O\subseteq G(\A)$ via $G(\Q)\subseteq G(\A)$ (\texttt{I.topgrp.def:gl2-adelic}).
