For $\delta\in G(\Q)$ and $x\in G(\A)$ the number $\alpha(\HB(\delta x))$ depends only on the right coset $B(\Q)\delta$
(\texttt{I.decomp.thm:height-map-equivariance}). Let $c\in\R$.
\begin{enumerate}
  \item[(a)] For every $x\in G(\A)$ the set of cosets $B(\Q)\delta\in B(\Q)\backslash G(\Q)$ with $\alpha(\HB(\delta x))>c$ is finite.
  \item[(b)] For every compact set $\Omega\subseteq G(\A)$ the set of cosets $B(\Q)\delta\in B(\Q)\backslash G(\Q)$ such that
  $\alpha(\HB(\delta x))>c$ for some $x\in\Omega$ is finite.
\end{enumerate}
