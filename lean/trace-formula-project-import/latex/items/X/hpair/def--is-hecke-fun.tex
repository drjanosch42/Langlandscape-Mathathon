Let $G$ be a group, $U\le G$ a subgroup and $R_0$ a commutative ring. A function $f\colon G\to R_0$ is a \emph{Hecke function} for $U$ if (i) $f(ux)=f(x)$ and (ii) $f(xu)=f(x)$ for all $u\in U$ and $x\in G$, and (iii) the support of $f$ meets only finitely many left cosets $xU$, i.e.\ the image of $\operatorname{supp}f$ in $G/U$ is finite.
