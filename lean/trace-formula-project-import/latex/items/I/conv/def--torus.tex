Let $R$ be a commutative ring. The \emph{diagonal torus} $T(R)\subseteq\GL_2(R)$ is the set of invertible diagonal
matrices, $T(R)=\{g\in\GL_2(R):g_{12}=g_{21}=0\}$; it is a subgroup of $\GL_2(R)$. For $t_1,t_2\in R^\times$ we write
$\diag(t_1,t_2)\in T(R)$ for the diagonal matrix with entries $t_1,t_2$.
