Let $R$ be a commutative ring. For $x\in R$ let $n(x)=\begin{psmallmatrix}1&x\\0&1\end{psmallmatrix}\in\GL_2(R)$
(its inverse is $n(-x)$). The \emph{unipotent subgroup} is $N(R)=\{n(x):x\in R\}\subseteq\GL_2(R)$; the map
$n\colon R\to\GL_2(R)$ is an injective group homomorphism from the additive group of $R$, with image $N(R)$.
