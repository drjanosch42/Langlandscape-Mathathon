Let $F$ be a non-archimedean local field, $G=\GL_2(F)$ and $K=K_F$. The \emph{spherical Hecke algebra}
$\mathcal H(G,K)$ is the set of functions $f\colon G\to\C$ such that
\begin{enumerate}[label=(\roman*)]
\item $f(kgk')=f(g)$ for all $g\in G$ and $k,k'\in K$, and
\item the set $\{gK:f(g)\neq0\}\subseteq G/K$ of left cosets on which $f$ does not vanish is finite,
\end{enumerate}
with pointwise addition and scalar multiplication and the convolution product
\[
  (f_1*f_2)(x)=\sum_{yK\in G/K}f_1(y)\,f_2(y^{-1}x)\qquad(x\in G).
\]
With this product, $\mathcal H(G,K)$ is an associative $\C$-algebra with unit $1_K$, the characteristic function
of $K$.
