Let $F$ be a non-archimedean local field, $G=\GL_2(F)$, and let $(\pi,V)$ and $(\sigma,W)$ be representations of $G$ on
complex vector spaces. Every $G$-equivariant $\C$-linear map $\varphi\colon V\to W$ maps $V(N)$ into $W(N)$, so it
induces a $\C$-linear map $\varphi_N\colon V_N\to W_N$, $\varphi_N(v+V(N))=\varphi(v)+W(N)$, which is
$T(F)$-equivariant: $\varphi_N\circ\pi_N(t)=\sigma_N(t)\circ\varphi_N$ for $t\in T(F)$. Moreover
$(\mathrm{id}_V)_N=\mathrm{id}_{V_N}$ and $(\psi\circ\varphi)_N=\psi_N\circ\varphi_N$ for every further $G$-equivariant
linear map $\psi\colon W\to W'$.
