Let $F$ be a non-archimedean local field, $G=\GL_2(F)$, let $U$, $V$, $W$ be smooth representations of $G$, and let
$\alpha\colon U\to V$ and $\beta\colon V\to W$ be $G$-equivariant $\C$-linear maps with $\operatorname{im}\alpha=\ker\beta$.
Then $\operatorname{im}\alpha_N=\ker\beta_N$ for the induced maps (\cref{I.smooth.thm:jacquet-functorial}) $\alpha_N\colon U_N\to V_N$ and
$\beta_N\colon V_N\to W_N$. Moreover, if $\alpha$ is injective then so is $\alpha_N$, and if $\beta$ is surjective then so
is $\beta_N$.
