For an integer $N\ge1$ let $\mathrm{red}_N\colon\Zhat\to\Z/N\Z$ be the ring homomorphism with kernel $N\Zhat$ that
extends the reduction $\Z\to\Z/N\Z$. Let $\chi\colon\Zhat^\times\to\C^\times$ be a continuous homomorphism. Then
there are an integer $N\ge1$ and a Dirichlet character $\chi_N\colon(\Z/N\Z)^\times\to\C^\times$ with
$\chi(u)=\chi_N(\mathrm{red}_N(u))$ for all $u\in\Zhat^\times$. In particular $\chi$ has finite order:
$\chi^n=1$ for some $n\ge1$.
