The group of \emph{ideles} of $\Q$ is the group of units $\A^\times$ of the ring $\A$, with the units topology: the
topology for which $x\mapsto(x,x^{-1})$ is a homeomorphism of $\A^\times$ onto its image in $\A\times\A$.
Explicitly, $x\in\A$ is a unit if and only if $x_\infty\neq0$, $x_p\neq0$ for all $p$, and $x_p\in\Zp^\times$ for all
but finitely many $p$.
