The ring of \emph{finite adeles} is the restricted product
\[
  \Af=\textstyle\prod'_p(\Qp,\Zp)=\{x=(x_p)_p\in\prod_p\Qp:\ x_p\in\Zp\text{ for all but finitely many primes }p\},
\]
with componentwise addition and multiplication. For a finite set $S$ of primes let
$\A_{f,S}=\prod_{p\in S}\Qp\times\prod_{p\notin S}\Zp\subseteq\Af$, with the product topology. $\Af$ carries the
\emph{restricted product topology}: $U\subseteq\Af$ is open if and only if $U\cap\A_{f,S}$ is open in $\A_{f,S}$ for
every finite set $S$ of primes.
