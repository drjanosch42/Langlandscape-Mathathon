Let $a,b\in\Z$, $\Oord$ an order of $\Bq$, $K$ a field and $k\in\N$; for every class $c\in X(\Oord)$ fix a representative
$x_c\in\Bhat^\times$. For functions $f,g\colon\Bhat^\times\to V_{k-2}(K)$ the \emph{norm-weighted pairing} is
\[
  \langle f,g\rangle=\sum_{c\in X(\Oord)}\frac{\nu(x_c)^{k-2}}{\abs{\Gamma_{x_c}}}\,\beta_{k-2}\bigl(f(x_c),g(x_c)\bigr)\in K.
\]
Here the sum is $0$ if $X(\Oord)$ is infinite and $1/\abs{\Gamma}$ is $0$ if $\Gamma$ is infinite; neither happens for $a,b<0$.
