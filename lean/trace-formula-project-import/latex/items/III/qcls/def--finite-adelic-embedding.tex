Let $a,b\in\Z$. The embedding $\iota\colon\Bq\to\Bhat$ of \cref{III.qcls.def:finite-adelic-algebra} is the ring homomorphism obtained by base change along the diagonal
embedding $\Q\to\Af$, that is $\iota(x_0+x_1i+x_2j+x_3k)=\iota_0(x_0)+\iota_0(x_1)i+\iota_0(x_2)j+\iota_0(x_3)k$ with $\iota_0\colon\Q\to\Af$ the diagonal.
