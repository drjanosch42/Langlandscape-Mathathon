Let $a,b\in\Z$, and let $\Binf=\Bq_\R$ with the topology for which the coordinate map $\Binf\to\R^4$ is a homeomorphism. The map
$x\mapsto(x_\infty,x_f)$, base change along the projections $\A\to\R$ and $\A\to\Af$, is an isomorphism of topological groups
$\BA^\times\cong\Binf^\times\times\Bhat^\times$ (units topologies).
