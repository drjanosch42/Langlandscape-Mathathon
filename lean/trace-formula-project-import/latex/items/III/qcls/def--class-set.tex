Let $a,b\in\Z$ and let $\Oord$ be an order of $\Bq$. The \emph{class set} of $\Oord$ is the set of double cosets
\[
  X(\Oord)=\Bq^\times\backslash\Bhat^\times/\Ohat^\times=\{\iota(\Bq^\times)\,x\,\Ohat^\times:x\in\Bhat^\times\},
\]
where $\iota(\Bq^\times)\le\Bhat^\times$ is the image of $\Bq^\times$ (\cref{III.qcls.def:finite-adelic-algebra}); $\Bq^\times$ acts on the left and
$\Ohat^\times$ on the right. We write $[x]$ for the class of $x\in\Bhat^\times$.
