Let $a,b\in\Z$ and let $\Oord$ be an order of $\Bq$. The set $\Ohat^\times=\{u\in\Bhat^\times:u\in\Ohat\text{ and }u^{-1}\in\Ohat\}$ of
\cref{III.qcls.def:order-completion} is a subgroup of $\Bhat^\times$: $\Ohat$ is closed under multiplication and contains $1$ (it is the $\Zhat$-span of the subring $\iota(\Oord)$).
