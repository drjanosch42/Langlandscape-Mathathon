For $D,M,k,n\in\N$ and a function $F\colon\Z\to\Q$ \emph{Eichler's expression} is
\[
\begin{aligned}
  \EichB(D,M,k,n;F)={}&C(k,n)\prod_{p\mid D}(p-1)\cdot\dedpsi(M)\\
  &+\sum_{\substack{t\in\Z\\ t^2<4n}}P_k(t,n)\sum_{f\in\Ford(t,n)}\frac{h(\Delta_f)}{\wnum(\Delta_f)}\prod_{p\mid D}\mD_p(\Delta_f)\cdot F(\Delta_f)\in\Q,
\end{aligned}
\]
where $\Delta_f=(t^2-4n)/f^2$, the products run over the primes dividing $D$ (empty if $D=0$), $C(k,n)=\frac{k-1}{12}r^{k-2}$ if $n=r^2$ with
$r\in\N$ and $C(k,n)=0$ if $n$ is not a square ($k-1$ computed in $\Q$, the exponent $k-2$ read as $\max(k-2,0)$), and $\dedpsi$, $P_k$, $\Ford$, $h$,
$\wnum$, $\mD_p$ are as in
\cref{III.ef.def:dedekind-psi,III.ef.def:hecke-polynomial,III.ef.def:order-index-set,III.ef.def:class-number-forms,III.ef.def:unit-number,III.ef.def:local-factor-ramified}.
