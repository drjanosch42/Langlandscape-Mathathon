Let $\Oord_{11}$ be Pizer's order of $\Bq(-1,-11)$. Its class set consists of two classes $c_1\ne c_2$ with $\abs{\Gamma_{x_{c_1}}}=4$ and
$\abs{\Gamma_{x_{c_2}}}=6$, and in the ordering $(c_1,c_2)$
\[
  \Brandt1=\begin{pmatrix}1&0\\0&1\end{pmatrix},\qquad\Brandt2=\begin{pmatrix}1&2\\3&0\end{pmatrix},
\]
and $\Brandt3$ has characteristic polynomial $(X-4)(X+1)$, i.e.\ trace $3$ and determinant $-4$.
