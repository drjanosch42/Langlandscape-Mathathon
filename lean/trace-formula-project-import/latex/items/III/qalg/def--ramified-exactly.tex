Let $a,b\in\Z$ and $D\in\N$. The quaternion algebra $\Bq(a,b)$ is \emph{definite and ramified exactly at $D$}, written $\operatorname{RamEx}(a,b,D)$,
if $a<0$, $b<0$, $D$ is squarefree, and for every prime $p$
\[
  \hilb abp=-1\iff p\mid D,
\]
with the Hilbert symbol of \cref{III.qalg.def:hilbert-symbol}.
