Let $a,b\in\Z$ and let $\Oord$ be an order of $\Bq$, with a $\Z$-basis $e_1,\dots,e_4$ fixed once and for all ($\Oord$ is free of
rank $4$). The \emph{discriminant} of $\Oord$ is
\[
  d(\Oord)=\det\bigl(\trd(e_\mu\bar e_\nu)\bigr)_{\mu,\nu=1}^{4}\in\Z.
\]
(The entries are integers by \cref{III.qord.lem:order-integral}; another $\Z$-basis changes the matrix to $P(\cdot)P^{\mathsf T}$ with
$\det P=\pm1$, so $d(\Oord)$ does not depend on the basis.)
