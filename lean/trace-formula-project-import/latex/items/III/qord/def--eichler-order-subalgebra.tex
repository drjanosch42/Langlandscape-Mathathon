Let $a,b\in\Z$, let $\Oord$ be an order of $\Bq$, $M\ge1$ and $\phi$ a level structure of level $M$ on $\Oord$. The set $\{x\in\Oord:\phi(x)_{21}=0\}$
is a $\Z$-subalgebra of $\Bq$ (the entry $(\phi(x)\phi(y))_{21}=\phi(x)_{21}\phi(y)_{11}+\phi(x)_{22}\phi(y)_{21}$ vanishes when both factors have lower left entry $0$).
It is the subring underlying the Eichler order $\Oord(M;\phi)$ of \cref{III.qord.def:eichler-order}.
