\end{tffidelity}
\end{tfformal}
\begin{proof}[Lean proof]
($\Rightarrow$) Let $\mu$ be a Haar measure and $g\in G$. Unimodularity (applied to the preimage as an image under $x\mapsto xg^{-1}$) gives $(\cdot\,g)_*\mu=\mu$. Choose a continuous compactly supported $f\ge0$ with $f(1)>0$; then $\int f\ne0$ and Mathlib's formula $\Delta(g)=\int f\,\dd(\cdot g)_*\mu\big/\int f\,\dd\mu$ (\texttt{haarScalarFactor\_eq\_integral\_div}) gives $\Delta(g)=1$. ($\Leftarrow$) If the modular character is trivial, then $(\cdot\,g^{-1})_*\mu=\Delta(g^{-1})\cdot\mu=\mu$ (\texttt{map\_right\_mul\_eq\_modularCharacterFun\_smul}), so $\mu(Eg)=\mu(E)$. Mathlib's $\Delta$ satisfies $(\cdot\,g)_*\mu=\Delta(g)\mu$, the reciprocal of A's convention; the statement is invariant.
\end{proof}
