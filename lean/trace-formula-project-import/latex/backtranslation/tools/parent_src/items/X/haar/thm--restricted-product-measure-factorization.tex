In the situation of \cref{X.haar.def:restricted-product-measure}, let $f_i\colon G_i\to\C$ be $\mu_i$-integrable
functions such that $f_i=1_{K_i}$ for all but finitely many $i$. Then $f(x)=\prod_if_i(x_i)$ (for each $x\in G$ all but
finitely many factors equal $1$) is integrable for $\bigotimes'_i\mu_i$, and
\[
  \int_Gf\,\dd\Bigl(\bigotimes\nolimits'_i\mu_i\Bigr)=\prod_i\int_{G_i}f_i\,\dd\mu_i,
\]
where all but finitely many factors equal $1$. In particular, for Borel sets $E_i\subseteq G_i$ with $E_i=K_i$ for all
but finitely many $i$, $\bigl(\bigotimes'_i\mu_i\bigr)\bigl(\prod_iE_i\bigr)=\prod_i\mu_i(E_i)$.
