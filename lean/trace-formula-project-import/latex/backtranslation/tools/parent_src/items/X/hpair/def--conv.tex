For $f_1,f_2\in\mathcal H(G,U;R_0)$ the \emph{convolution} is the function $G\to R_0$, $x\mapsto (f_1*f_2)(x)=\sum_{yU\in G/U} f_1(y)\,f_2(y^{-1}x)$, the sum of the convolution terms of \cref{X.hpair.def:conv-term} over all cosets (only finitely many are non-zero, those with $f_1(y)\neq0$). This is the convolution for the counting measure on $G/U$, i.e.\ for the Haar measure with $\operatorname{vol}(U)=1$.
