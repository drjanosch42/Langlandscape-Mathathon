Let $F$ be a field with a topology in which addition and multiplication are continuous, inversion is continuous on
$F^\times$, and points are closed. Give $\Mat_2(F)=F^{2\times2}$ the product topology and $\GL_2(F)$ the units
topology. Then the inclusion $\GL_2(F)\to\Mat_2(F)$ is an open embedding, and its image is
$\{X\in\Mat_2(F):\det X\neq0\}$.
