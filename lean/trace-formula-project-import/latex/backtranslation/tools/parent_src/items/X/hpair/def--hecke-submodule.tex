In the situation of \cref{X.hpair.def:is-hecke-fun}, the Hecke functions form an $R_0$-submodule of the module $R_0^G$ of all functions $G\to R_0$: the zero function is a Hecke function, and sums and $R_0$-multiples of Hecke functions are again Hecke functions (the finiteness in (iii) is preserved because the support of a sum lies in the union of the supports, and that of a multiple in the support of the function).
