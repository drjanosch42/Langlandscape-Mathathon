The multiplication on $\mathcal H(G,U;R_0)$ is $f_1\cdot f_2=f_1*f_2$, the convolution of \cref{X.hpair.def:conv}. That $f_1*f_2$ is again a Hecke function means: it is bi-$U$-invariant, and its support lies in $\operatorname{supp}f_1\cdot\operatorname{supp}f_2$, which meets only finitely many cosets $xU$.
