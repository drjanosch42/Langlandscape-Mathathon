Let $G$ be a group, $U\le G$ a subgroup, $R_0$ a commutative ring and $V$ an $R_0$-module. For functions $\varphi\colon G\to R_0$ and
$f\colon G\to V$ the function $\varphi\cdot f\colon G\to V$ is
\[
  (\varphi\cdot f)(x)=\sum_{yU\in G/U}\varphi(y)\,f(xy),
\]
where $y$ runs through a fixed set of representatives of $G/U$ (the sum is a finite sum when only finitely many terms are non-zero,
and $0$ otherwise).
