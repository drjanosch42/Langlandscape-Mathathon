Let $G$, $\Gamma$, $\mu$ be as in \cref{X.quot.def:quotient-measure}, and assume that $G$ is unimodular. Then
$\mu_{\Gamma\backslash G}$ is invariant under right translations: $\mu_{\Gamma\backslash G}(Eh)=\mu_{\Gamma\backslash G}(E)$
for all Borel $E\subseteq\Gamma\backslash G$ and $h\in G$, where $Eh=\{\Gamma gh:\Gamma g\in E\}$.
