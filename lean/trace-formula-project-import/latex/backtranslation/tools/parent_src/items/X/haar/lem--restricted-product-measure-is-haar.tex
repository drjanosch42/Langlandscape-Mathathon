In the situation of \cref{X.haar.def:restricted-product-measure} (countable index set, $G_i$ second countable locally compact Hausdorff topological groups with Borel $\sigma$-algebra, $K_i$ compact open, $\mu_i$ Haar measures with $\mu_i(K_i)=1$ for almost all $i$), the measure $\bigotimes'\mu_i$ is a left Haar measure on $\prod'_i(G_i,K_i)$ with value $\prod_i\mu_i(K_i)$ on the box $\prod_iK_i$.
