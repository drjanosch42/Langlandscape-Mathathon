The \emph{Hecke algebra} $\mathcal H(G,U;R_0)$ is the underlying type of the submodule of \cref{X.hpair.def:hecke-submodule}, i.e.\ the set of Hecke functions with its $R_0$-module structure. Its ring structure is given by the multiplication of \cref{X.hpair.def:mul-instance} and the unit of \cref{X.hpair.def:one-instance}.
