Let $G$, $\Gamma$, $\mu$ be as in \cref{X.quot.def:quotient-measure}. For every Borel function
$f\colon G\to[0,\infty]$, the function $\Gamma g\mapsto\sum_{\gamma\in\Gamma}f(\gamma g)$ on $\Gamma\backslash G$ is Borel and
\[
  \int_Gf\,\dd\mu=\int_{\Gamma\backslash G}\sum_{\gamma\in\Gamma}f(\gamma g)\,\dd\mu_{\Gamma\backslash G}(\Gamma g).
\]
For every $\mu$-integrable $f\colon G\to\C$, the series $\sum_{\gamma\in\Gamma}f(\gamma g)$ converges absolutely for
$\mu_{\Gamma\backslash G}$-almost every $\Gamma g$, the resulting function is $\mu_{\Gamma\backslash G}$-integrable, and the
same formula holds.
