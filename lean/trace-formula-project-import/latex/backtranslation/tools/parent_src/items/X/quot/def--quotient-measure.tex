Let $G$ and $\Gamma$ be as in \cref{X.quot.thm:exists-fundamental-domain}, let $\Gamma\backslash G=\{\Gamma g:g\in G\}$
carry the quotient topology and its Borel $\sigma$-algebra, and let $\pi\colon G\to\Gamma\backslash G$ be the quotient
map. For a left Haar measure $\mu$ on $G$, the \emph{quotient measure} $\mu_{\Gamma\backslash G}$ on $\Gamma\backslash G$
is
\[
  \mu_{\Gamma\backslash G}(E)=\mu\bigl(D\cap\pi^{-1}(E)\bigr)\qquad(E\subseteq\Gamma\backslash G\text{ Borel}),
\]
where $D$ is a Borel fundamental domain for $\Gamma$. It does not depend on the choice of $D$, and it is finite on
compact sets.
