Let $G$ be a locally compact, Hausdorff, second countable group with its Borel $\sigma$-algebra, $H\le G$ a closed
subgroup which is unimodular (\cref{X.haar.def:is-unimodular}), and $\mu_G$, $\mu_H$ left Haar measures on $G$ and $H$. Let
$H\backslash G=\{Hx:x\in G\}$ carry the quotient topology and its Borel $\sigma$-algebra. For a continuous $f\colon G\to\C$ with
compact support put
\[
  f^\natural(Hx)=\int_Hf(hx)\,\dd\mu_H(h)\qquad(x\in G);
\]
this depends only on $Hx$, because $\mu_H$ is right invariant. A Borel measure $\nu$ on $H\backslash G$ is a \emph{Weil measure} for
$(\mu_G,\mu_H)$ if it is finite on compact sets and
\[
  \int_Gf\,\dd\mu_G=\int_{H\backslash G}f^\natural\,\dd\nu
\]
for every continuous $f\colon G\to\C$ with compact support.
