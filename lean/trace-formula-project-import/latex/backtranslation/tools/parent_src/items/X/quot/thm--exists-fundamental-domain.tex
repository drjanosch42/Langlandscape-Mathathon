Let $G$ be a locally compact, Hausdorff, second countable group with its Borel $\sigma$-algebra, and let $\Gamma\le G$ be
a discrete subgroup (in the subspace topology). Then $\Gamma$ is countable and closed in $G$, and there is a Borel set
$D\subseteq G$ such that $G=\bigsqcup_{\gamma\in\Gamma}\gamma D$ (disjoint union). Such a $D$ is a \emph{Borel
fundamental domain} for $\Gamma$; it meets every coset $\Gamma g$ in exactly one point.
