Let $G$ be a locally compact Hausdorff group, $H\le G$ a closed subgroup and $\mu_H$ a left Haar measure on $H$. A
\emph{Bruhat function} for $(H,\mu_H)$ is a continuous function $\beta\colon G\to[0,\infty)$ such that
\begin{enumerate}
  \item[(i)] for every compact $C\subseteq G$ the set $\supp\beta\cap CH$ is compact, and
  \item[(ii)] $\int_H\beta(xh)\,\dd\mu_H(h)=1$ for every $x\in G$.
\end{enumerate}
