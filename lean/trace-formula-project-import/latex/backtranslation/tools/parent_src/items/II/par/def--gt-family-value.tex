For a $(G,T)$-family $c$ (\cref{II.par.def:gt-family}) put, for $\lambda\in\R$, $\lambda\neq0$,
\[
  c_T(\lambda)=\sum_{P\in\mathcal P(T)}c(\lambda,P)\,\theta_P(\lambda)^{-1}=\frac{c(\lambda,B)-c(\lambda,\Bbar)}{\lambda}
\]
(\cref{II.par.def:theta}), and let the \emph{value} of $c$ be
\[
  c_T=\lim_{\lambda\to0,\ \lambda\neq0}c_T(\lambda)
\]
(by convention $c_T=0$ if the limit does not exist; it always exists, \cref{II.par.thm:gt-family-derivative}).
