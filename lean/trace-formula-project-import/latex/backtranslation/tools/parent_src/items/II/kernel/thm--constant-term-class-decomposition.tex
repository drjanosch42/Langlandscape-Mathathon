Let $f$, $\dd u$ be as in \cref{II.kernel.def:constant-term-kernel}. For all $x,y\in G(\A)^1$, only finitely many classes $\mathcal O$ have
$K_{B,\mathcal O}(x,y)\neq0$, and
\[
  K_B(x,y)=\sum_{\mathcal O}K_{B,\mathcal O}(x,y)
\]
(\cref{II.kernel.def:class-constant-term-kernel}). If $\mathcal O$ is elliptic (\cref{II.kernel.def:class-types}), then $K_{B,\mathcal O}=0$.
