Let $f\colon G(\A)^1\to\C$ be continuous with compact support. The \emph{kernel} of $f$ is the function on
$G(\A)^1\times G(\A)^1$
\[
  K_f(x,y)=\sum_{\gamma\in G(\Q)}f(x^{-1}\gamma y),
\]
the sum of the family $(f(x^{-1}\gamma y))_{\gamma\in G(\Q)}$ (by convention $0$ if the family is not summable; for each $(x,y)$ only
finitely many terms are non-zero, \cref{II.kernel.thm:kernel-locally-finite}).
