For a prime $p$ and $x\in\GL_2(\Qp)$ with rows $e_1x=(x_{11},x_{12})$ and $e_2x=(x_{21},x_{22})$, put $\norm{(c,d)}_p=\max(\abs c_p,\abs d_p)$ and
\[
  v_p(x)=\log\norm{e_1x}_p+\log\norm{e_2x}_p-\log\abs{\det x}_p .
\]
The function $v_p$ is continuous, left invariant under $T(\Qp)$ and right invariant under $K_p$, and $v_p=0$ on $T(\Qp)K_p$.
