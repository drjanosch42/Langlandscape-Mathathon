Let $\varphi\colon G(\A)^1\to\C$ be smooth (\texttt{I.autf.def:smooth-norm-one}), left $G(\Q)$-invariant and of uniform moderate growth (\texttt{I.autf.def:moderate-growth}),
and let $T\in\aB$ with $\alpha(T)\ge0$. Then $\Lambda^T\varphi$ (\cref{II.trunc.def:truncation}) is bounded on $G(\A)^1$, and for every left Haar measure $\mu$ on $G(\A)$ the
function it induces on $X=G(\Q)\backslash G(\A)^1$ is Borel and square-integrable for the measure of \texttt{I.quot.def:automorphic-quotient-measure}; that is, it defines an
element of $\Ltwo(X)$ (\texttt{I.quot.def:l2-automorphic}).
