Let $\alpha^\vee=(1,-1)\in\aBG$ be the \emph{coroot}. We identify the dual space $(\aBG)^*$ with $\R$ by $\Lambda\mapsto\Lambda(\alpha^\vee)$, and
we write $\Lambda_\lambda$ for the linear form with $\Lambda_\lambda(\alpha^\vee)=\lambda$, so that $\Lambda_\lambda(r\alpha^\vee)=r\lambda$ for $r\in\R$. The Haar
measure on $\aBG$ is normalized by $\vol(\aBG/\Z\alpha^\vee)=1$. For $P\in\mathcal P(T)$ (\cref{II.par.def:standard-parabolics}) and $\lambda\in\R$ put
\[
  \theta_B(\lambda)=\lambda,\qquad\theta_{\Bbar}(\lambda)=-\lambda .
\]
