Let $\gamma\in\GL_2(\Q)$ with $\Delta(\gamma)<0$. Then $U_\gamma$ is compact and open in $G_\gamma(\A)^1$ (\cref{II.orb.def:torus-unit-subgroup}), $\nu_\gamma^{\mathrm{std}}$ is a left Haar
measure on $G_\gamma(\A)^1$, and $\nu_\gamma^{\mathrm{std}}(U_\gamma)=1$ (\cref{II.orb.def:standard-torus-measure}).
