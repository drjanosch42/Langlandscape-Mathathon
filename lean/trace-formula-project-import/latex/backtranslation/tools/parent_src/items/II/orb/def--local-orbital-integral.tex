Let $F$ be $\R$ or $\Qp$ for a prime $p$, let $\gamma\in\GL_2(\Q)\subseteq\GL_2(F)$, and let $\nu$ be a measure on the coset space $G_\gamma(F)\backslash G(F)$,
$G(F)=\GL_2(F)$ (\cref{II.orb.def:centralizer}). For $f\colon G(F)\to\C$ the function $x\mapsto f(x^{-1}\gamma x)$ depends only on the coset $G_\gamma(F)x$. The
\emph{local orbital integral} is
\[
  O_{\gamma,F}(f;\nu)=\int_{G_\gamma(F)\backslash G(F)}f(x^{-1}\gamma x)\,\dd\nu(x),
\]
a Bochner integral (by convention $0$ if the integrand is not $\nu$-integrable). We write $O_{\gamma,p}$ for $F=\Qp$ and $O_{\gamma,\infty}$ for $F=\R$.
