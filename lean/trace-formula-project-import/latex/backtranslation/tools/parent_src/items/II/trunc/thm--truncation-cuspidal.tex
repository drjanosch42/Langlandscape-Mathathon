Let $\varphi\colon G(\A)^1\to\C$ have vanishing constant term, $\varphi_B(x)=0$ for all $x\in G(\A)^1$ (\texttt{I.cusp.def:constant-term}). Then
$\Lambda^T\varphi=\varphi$ for every $T\in\aB$ (\cref{II.trunc.def:truncation}). In particular $\Lambda^T\varphi=\varphi$ for every cusp form
$\varphi$ (\texttt{I.cusp.def:cusp-form}) and every $T\in\aB$.
