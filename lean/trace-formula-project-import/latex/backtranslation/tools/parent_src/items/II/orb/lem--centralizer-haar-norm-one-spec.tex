Let $\gamma\in\GL_2(\Q)$, $\nu$ a left Haar measure on $G_\gamma(\A)$ and $\nu^1$ the measure of \cref{II.orb.def:centralizer-haar-norm-one}.
Then $\nu^1(E)=\nu(\{a(r)g:1\le r<e,\ g\in E\})$ for every Borel $E\subseteq G_\gamma(\A)^1$, $\nu^1$ is a left Haar measure on $G_\gamma(\A)^1$, and for every
Borel $F\colon G(\A)\to[0,\infty]$
\[
  \int_{G_\gamma(\A)}F(h)\,\dd\nu(h)=\int_0^\infty\int_{G_\gamma(\A)^1}F\bigl(a(r)g\bigr)\,\dd\nu^1(g)\,\frac{\dd r}{r}.
\]
