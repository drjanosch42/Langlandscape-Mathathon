Let $T\in\aB$ with $\alpha(T)\ge0$ and $x\in G(\A)^1$. For $\delta\in G(\Q)$ the number $\tau_B(\HB(\delta x)-T)$ (\texttt{I.conv.def:chamber-functions})
depends only on the coset $B(\Q)\delta$, it is non-zero for at most one coset $B(\Q)\delta\in B(\Q)\backslash G(\Q)$, and
\[
  F^G(x,T)+\sum_{\delta\in B(\Q)\backslash G(\Q)}\tau_B(\HB(\delta x)-T)=1,
\]
with $F^G$ as in \cref{II.trunc.def:compact-part}.
