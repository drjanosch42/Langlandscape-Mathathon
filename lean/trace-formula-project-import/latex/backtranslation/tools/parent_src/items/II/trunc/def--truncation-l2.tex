Let $\mu$ be a left Haar measure on $G(\A)$, $X=G(\Q)\backslash G(\A)^1$ with the measure of \texttt{I.quot.def:automorphic-quotient-measure}, $p\colon G(\A)^1\to X$ the quotient
map, and $T\in\aB$. Fix a lift $\tilde x\in G(\A)^1$, $p(\tilde x)=\dot x$, of every $\dot x\in X$, and for every $\varphi\in\Ltwo(X)$ (\texttt{I.quot.def:l2-automorphic}) a Borel
function $f_\varphi\colon X\to\C$ in the class $\varphi$. Put $g_\varphi(\dot x)=\Lambda^T(f_\varphi\circ p)(\tilde x)$ (\cref{II.trunc.def:truncation}). The map
$P^T\colon\Ltwo(X)\to\Ltwo(X)$ is $P^T\varphi=$ the class of $g_\varphi$ if $g_\varphi$ is almost everywhere equal to a Borel function and square-integrable, and $P^T\varphi=0$
otherwise.
