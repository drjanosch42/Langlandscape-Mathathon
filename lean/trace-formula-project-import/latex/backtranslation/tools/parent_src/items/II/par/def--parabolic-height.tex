Let $\HB\colon G(\A)\to\aB$ be the height map (\texttt{I.decomp.def:height-map}), $w$ the Weyl element
(\texttt{I.conv.def:weyl-element}), and let $w$ act on $\aB$ by $w(h_1,h_2)=(h_2,h_1)$. For $P\in\mathcal P(T)$
(\cref{II.par.def:standard-parabolics}) the \emph{height map} $H_P\colon G(\A)\to\aB$ is $H_B=\HB$ and
\[
  H_{\Bbar}(x)=w\,\HB(w^{-1}x)\qquad(x\in G(\A)).
\]
