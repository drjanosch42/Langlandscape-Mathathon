Let $f\colon G(\A)^1\to\C$ be continuous with compact support, $\mathcal O$ a hyperbolic or elliptic class (\cref{II.kernel.def:class-types}) and
$\gamma\in\mathcal O$, with centralizer $G_\gamma(\Q)$ (\texttt{II.orb.def:centralizer}). Then for all $x,y\in G(\A)^1$
\[
  K_{\mathcal O}(x,y)=\sum_{\delta\in G_\gamma(\Q)\backslash G(\Q)}f\bigl(x^{-1}\delta^{-1}\gamma\delta\,y\bigr),
\]
the sum over the right cosets $G_\gamma(\Q)\delta$ (the term depends only on the coset), with finitely many non-zero terms.
