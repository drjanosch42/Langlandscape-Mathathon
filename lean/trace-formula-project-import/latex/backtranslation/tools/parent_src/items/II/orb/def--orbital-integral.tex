Let $\gamma\in\GL_2(\Q)$, regarded as an element of $G(\A)^1$, and let $G_\gamma(\A)^1\backslash G(\A)^1$ be the space of right cosets of the closed
subgroup $G_\gamma(\A)^1$ (\cref{II.orb.def:centralizer-norm-one,II.orb.thm:centralizer-closed}) with the quotient topology and its Borel $\sigma$-algebra.
For $f\colon G(\A)^1\to\C$ the function $x\mapsto f(x^{-1}\gamma x)$ on $G(\A)^1$ depends only on the coset $G_\gamma(\A)^1x$. For a measure $\nu$ on
$G_\gamma(\A)^1\backslash G(\A)^1$ the \emph{orbital integral} is
\[
  O_\gamma(f;\nu)=\int_{G_\gamma(\A)^1\backslash G(\A)^1}f(x^{-1}\gamma x)\,\dd\nu(x),
\]
a Bochner integral (by convention $0$ if the integrand is not $\nu$-integrable).
