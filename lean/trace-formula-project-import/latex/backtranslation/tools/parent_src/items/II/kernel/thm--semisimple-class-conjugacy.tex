Let $\mathcal O$ be a geometric class (\cref{II.kernel.def:geometric-class,II.kernel.def:class-types}).
\begin{enumerate}
  \item[(a)] If $\mathcal O$ is hyperbolic or elliptic and $\gamma\in\mathcal O$, then $\mathcal O=\{\delta^{-1}\gamma\delta:\delta\in\GL_2(\Q)\}$ is a single conjugacy class.
  \item[(b)] If $\mathcal O=\mathcal O_{a,b}$ is hyperbolic, then $\mathcal O\cap T(\Q)=\{\diag(a,b),\diag(b,a)\}$.
  \item[(c)] If $\mathcal O$ is elliptic, then $\mathcal O\cap B(\Q)=\emptyset$.
  \item[(d)] If $\mathcal O=\mathcal O_z$ is central-unipotent, then $\mathcal O=\{z\cdot1\}\cup\{\delta^{-1}(z\,n(1))\delta:\delta\in\GL_2(\Q)\}$.
\end{enumerate}
Here $T(\Q)$, $B(\Q)$ are the diagonal and upper triangular subgroups of $\GL_2(\Q)$ (\texttt{I.conv.def:torus}, \texttt{I.conv.def:borel}) and
$n(1)=\begin{psmallmatrix}1&1\\0&1\end{psmallmatrix}$ (\texttt{I.conv.def:unipotent}).
