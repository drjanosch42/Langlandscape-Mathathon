For $x\in G(\A)$ and $T\in\aB$ the \emph{weight} $v(x,T)$ is the value $c_T$ (\cref{II.par.def:gt-family-value}) of the $(G,T)$-family
\[
  c(\lambda,P)=e^{\Lambda_\lambda(Y_P(x,T))}\qquad(P\in\mathcal P(T),\ \lambda\in\R),
\]
with $Y_P(x,T)$ as in \cref{II.par.def:y-vector} and $\Lambda_\lambda$ as in \cref{II.par.def:theta}.
