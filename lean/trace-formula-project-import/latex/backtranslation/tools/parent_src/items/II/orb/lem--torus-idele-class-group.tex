Let $\gamma\in\GL_2(\Q)$ with $\Delta(\gamma)<0$, let $E$ be a number field and $e\colon E\to\Mat_2(\Q)$ a homomorphism of $\Q$-algebras with $\gamma\in e(E)$. Then the
group $G_\gamma(\A)^1/G_\gamma(\Q)U_\gamma$ (\cref{II.orb.thm:centralizer-rat-points,II.orb.def:torus-unit-subgroup}) has exactly $h_E$ elements, $h_E$ the class number of $E$.
