Let $a,b\in\Q^\times$ with $a\neq b$ and $\gamma=\diag(a,b)\in\GL_2(\Q)$. Then $G_\gamma(R)=T(R)$ for every commutative $\Q$-algebra $R$
(\cref{II.orb.def:centralizer}, \texttt{I.conv.def:torus}). In particular $G_\gamma(\A)=T(\A)$ and
\[
  G_\gamma(\A)^1=T(\A)\cap G(\A)^1=\{\diag(t_1,t_2):t_1,t_2\in\A^\times,\ \abs{t_1t_2}_\A=1\}
\]
(\cref{II.orb.def:centralizer-norm-one}).
