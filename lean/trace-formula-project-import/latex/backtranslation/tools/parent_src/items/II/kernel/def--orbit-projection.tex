Let $o$ be a set of Dirichlet pairs. Let $S|_o$ be the set of $F$ in the symmetric part $\mathcal S$ of the continuous fibre space (\texttt{I.spec.def:m-symmetric-part}) that vanish almost everywhere outside $o$, i.e.\ $F(t,\eta)=0$ for almost every $t\in\R$ and every $\eta\notin o$. The \emph{orbit projection} $P_o$ is the orthogonal projection of $\Ltwo(X)$ onto the closure of
\[
  J(S|_o)+\operatorname{span}\{[\eta_\nu]:(\nu,\nu)\in o\},
\]
where $J$ is the Eisenstein transform (\texttt{I.spec.def:eisenstein-transform}) and $[\eta_\nu]$ the class of the residual character (\texttt{I.spec.def:residual-class}); the measure on $X$ is the standard one.
