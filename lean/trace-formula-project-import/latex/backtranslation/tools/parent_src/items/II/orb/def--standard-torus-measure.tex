For $\gamma\in\GL_2(\Q)$ let $\nu_\gamma^{\mathrm{std}}=\mathrm{haar}(U_\gamma)^{-1}\cdot\mathrm{haar}$, where $\mathrm{haar}$ is a fixed left Haar measure on $G_\gamma(\A)^1$ and $U_\gamma$ is as in
\cref{II.orb.def:torus-unit-subgroup}. If $\Delta(\gamma)<0$, then $\nu_\gamma^{\mathrm{std}}$ is the left Haar measure on $G_\gamma(\A)^1$ with $\nu_\gamma^{\mathrm{std}}(U_\gamma)=1$
(independent of the choice of $\mathrm{haar}$).
