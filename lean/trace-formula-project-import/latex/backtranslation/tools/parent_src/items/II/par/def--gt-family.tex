A \emph{$(G,T)$-family} is a pair $c=(c(\cdot,B),c(\cdot,\Bbar))$ of functions $\R\to\C$, indexed by $\mathcal P(T)$
(\cref{II.par.def:standard-parabolics}; the argument $\lambda\in\R$ stands for $\Lambda_\lambda\in(\aBG)^*$, \cref{II.par.def:theta}), such that both
functions are differentiable at $0$ and $c(0,B)=c(0,\Bbar)$.
