Let $\omega_0=\{n(u):u\in\A,\ u_\infty\in[-\tfrac12,\tfrac12],\ u_p=0\text{ for every prime }p\}\subseteq N(\A)$, let
$\mathfrak S=\mathfrak S(\omega_0,\sqrt3/2)$ be the Siegel set of \texttt{I.red.def:siegel-set}, and let $T\in\aB$ with
\[
  \alpha(T)\ge\log\frac2{\sqrt3}=\frac12\log\frac43 .
\]
Then for every $x\in G(\A)^1$, $F^G(x,T)=1$ (\cref{II.trunc.def:compact-part}) if and only if there is $\delta\in G(\Q)$ with
$\delta x\in\mathfrak S$ and $\alpha(\HB(\delta x))\le\alpha(T)$. That is, $\{x\in G(\A)^1:F^G(x,T)=1\}=G(\Q)\,\mathfrak S^T$ with
$\mathfrak S^T=\{s\in\mathfrak S:\alpha(\HB(s))\le\alpha(T)\}$.
