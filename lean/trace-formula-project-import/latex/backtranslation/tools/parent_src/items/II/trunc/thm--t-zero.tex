Let $s\colon\aB\to\aB$ be the action of the non-trivial element of the Weyl group, $s(h_1,h_2)=(h_2,h_1)$ (so $s^{-1}=s$), and let $w$ be the
Weyl element of \texttt{I.conv.def:weyl-element}, regarded as an element of $G(\Q)\subseteq G(\A)$. There is exactly one $T_0\in\aBG$
(\texttt{I.conv.def:space-a-b-g}) with
\[
  \HB(w^{-1})=T_0-s^{-1}T_0 ,
\]
and this point is $T_0=0$.
