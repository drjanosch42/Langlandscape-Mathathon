For every $h\in\aB$, $\tau_B(h)=\hat\tau_B(h)$ (\texttt{I.conv.def:chamber-functions}), and this common value is $1$ if $\alpha(h)>0$ and
$0$ if $\alpha(h)\le0$. In particular, for $H,T\in\aB$,
\[
  \tau_B(H-T)=\hat\tau_B(H-T)=\begin{cases}1&\alpha(H)>\alpha(T),\\0&\alpha(H)\le\alpha(T).\end{cases}
\]
