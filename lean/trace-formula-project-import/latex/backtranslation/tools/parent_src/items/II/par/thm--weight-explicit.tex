Let $x\in G(\A)$ and $T\in\aB$, and write $Y_P(x,T)=y_P\,\alpha^\vee$ with $y_P\in\R$ for $P\in\mathcal P(T)$ (\cref{II.par.def:y-vector,II.par.def:theta}). The
family of \cref{II.par.def:weight} is a $(G,T)$-family, and
\[
  v(x,T)=y_B-y_{\Bbar}=\alpha(T)-\tfrac12\,\alpha\bigl(\HB(x)\bigr)-\tfrac12\,\alpha\bigl(\HB(wx)\bigr),
\]
where $\alpha$ is the simple root (\texttt{I.conv.def:simple-root}), $\HB$ the height map (\texttt{I.decomp.def:height-map}) and $w$ the Weyl element
(\texttt{I.conv.def:weyl-element}). In particular $Y_B(x,T)-Y_{\Bbar}(x,T)=v(x,T)\,\alpha^\vee$: $v(x,T)$ is the signed length of the segment from
$Y_{\Bbar}(x,T)$ to $Y_B(x,T)$ in $\aBG$, measured in units of $\alpha^\vee$.
