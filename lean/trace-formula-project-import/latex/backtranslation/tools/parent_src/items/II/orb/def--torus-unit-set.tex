For $\gamma\in\GL_2(\Q)$ let $U_\gamma^{\mathrm{set}}$ be the subset of $G_\gamma(\A)^1$ of those $g$ such that for every prime $p$: $g_p\in\Qp+\Qp\gamma$, $\abs{\tr g_p}_p\le1$ and
$\abs{\det g_p}_p=1$. This is the underlying set of the subgroup $U_\gamma$ of \cref{II.orb.def:torus-unit-subgroup}.
