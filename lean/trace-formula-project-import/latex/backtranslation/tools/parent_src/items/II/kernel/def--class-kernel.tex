Let $f\colon G(\A)^1\to\C$ be continuous with compact support and $\mathcal O$ a geometric class (\cref{II.kernel.def:geometric-class}). The
\emph{class kernel} is the function on $G(\A)^1\times G(\A)^1$
\[
  K_{\mathcal O}(x,y)=\sum_{\gamma\in\mathcal O}f(x^{-1}\gamma y),
\]
the sum of the family $(f(x^{-1}\gamma y))_{\gamma\in\mathcal O}$ (by convention $0$ if the family is not summable; for each $(x,y)$ only finitely many
terms are non-zero, \cref{II.kernel.thm:class-decomposition}).
