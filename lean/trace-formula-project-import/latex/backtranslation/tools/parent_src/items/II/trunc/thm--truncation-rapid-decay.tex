Let $\varphi\colon G(\A)^1\to\C$ be smooth (\texttt{I.autf.def:smooth-norm-one}), left $G(\Q)$-invariant and of uniform moderate growth
(\texttt{I.autf.def:moderate-growth}), and let $T\in\aB$ with $\alpha(T)\ge0$. Then $\Lambda^T\varphi$ (\cref{II.trunc.def:truncation}) is rapidly decreasing
(\cref{II.trunc.def:rapidly-decreasing}): for every $N\in\R$ there is $C\in\R$ with $\abs{\Lambda^T\varphi(x)}\le C\,e^{-N\operatorname{ht}(x)}$ for all $x\in G(\A)^1$.
