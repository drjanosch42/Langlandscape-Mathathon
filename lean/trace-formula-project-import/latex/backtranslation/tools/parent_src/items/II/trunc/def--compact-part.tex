For $x\in G(\A)^1$ and $T\in\aB$ the \emph{characteristic function of the compact part} is
\[
  F^G(x,T)=\begin{cases}1&\operatorname{ht}(x)\le\alpha(T),\\0&\operatorname{ht}(x)>\alpha(T),\end{cases}
\]
with the height $\operatorname{ht}$ of \texttt{I.red.def:height-primitive} and the simple root $\alpha$ of \texttt{I.conv.def:simple-root}.
