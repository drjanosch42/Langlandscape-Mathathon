Let $a,b\in\Q^\times$ with $a\neq b$, $\gamma=\diag(a,b)$, $T\in\aB$, $f\colon G(\A)^1\to\C$, and let $\nu$ be a measure on
$G_\gamma(\A)^1\backslash G(\A)^1$ (\cref{II.orb.def:orbital-integral}). The function $x\mapsto f(x^{-1}\gamma x)\,v(x,T)$ on $G(\A)^1$, with the weight $v$ of
\cref{II.par.def:weight}, depends only on the coset $G_\gamma(\A)^1x$. The \emph{weighted orbital integral} is
\[
  J_T(\gamma,f;\nu)=\int_{G_\gamma(\A)^1\backslash G(\A)^1}f(x^{-1}\gamma x)\,v(x,T)\,\dd\nu(x),
\]
a Bochner integral (by convention $0$ if the integrand is not $\nu$-integrable).
