Let $f\colon G(\A)^1\to\C$ be continuous with compact support and $\dd u$ a Haar measure on $\A$ (so that its image $\dd n$ under
$u\mapsto n(u)$ is a Haar measure on $N(\A)$). The \emph{constant-term kernel} is the function on $G(\A)^1\times G(\A)^1$
\[
  K_B(x,y)=\int_\A\sum_{\gamma\in T(\Q)}f\bigl(x^{-1}\gamma\,n(u)\,y\bigr)\,\dd u,
\]
with $T(\Q)=\{\diag(q_1,q_2):q_1,q_2\in\Q^\times\}\subseteq G(\A)^1$ (\texttt{I.conv.def:torus}); the sum is the sum of the family (by convention $0$ if it is not summable) and the integral a
Bochner integral (by convention $0$ if the integrand is not integrable); see \cref{II.kernel.thm:constant-term-kernel-properties}.
