Let $\mu$ be a left Haar measure on $G(\A)$, $X=G(\Q)\backslash G(\A)^1$ with the measure $\dd\dot y$ of
\texttt{I.quot.def:automorphic-quotient-measure} (the quotient of $\mu^1$), $f\colon G(\A)^1\to\C$ continuous with compact
support, and $R(f)$ the operator on $\Ltwo(X)$ of \texttt{I.rep.def:automorphic-test-function-action}, formed with $\mu^1$. By \cref{II.kernel.thm:kernel-locally-finite}(c), $K_f(x,y)$ depends only on $\dot x=G(\Q)x$ and $\dot y=G(\Q)y$; write
$K_f(\dot x,\dot y)$. Let $\varphi\in\Ltwo(X)$. Then for every $\dot x\in X$ the function $\dot y\mapsto K_f(\dot x,\dot y)\varphi(\dot y)$ is
integrable on $X$, and
\[
  (R(f)\varphi)(\dot x)=\int_XK_f(\dot x,\dot y)\,\varphi(\dot y)\,\dd\dot y\qquad\text{for almost every }\dot x\in X.
\]
