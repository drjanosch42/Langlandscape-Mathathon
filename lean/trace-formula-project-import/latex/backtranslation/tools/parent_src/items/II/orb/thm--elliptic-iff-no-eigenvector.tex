Let $K$ be a field and $\gamma\in\GL_2(K)$. The following are equivalent:
\begin{enumerate}
  \item[(a)] $\gamma$ is elliptic;
  \item[(b)] the characteristic polynomial $P_\gamma$ has no root in $K$;
  \item[(c)] for every non-zero row vector $v\in K^2$ the vectors $v$ and $v\gamma$ are linearly independent, that is, the
  $2\times2$ matrix with rows $v$ and $v\gamma$ has non-zero determinant.
\end{enumerate}
In particular, an elliptic $\gamma$ does not lie in the centre $Z(K)$.
