Let $\Omega\subseteq G(\A)$ be compact. Then the set of geometric classes $\mathcal O$ (\cref{II.kernel.def:geometric-class}) for which there are
$\gamma\in\mathcal O$ and $x\in G(\A)$ with $x^{-1}\gamma x\in\Omega$ is finite. In particular, for every continuous $f\colon G(\A)^1\to\C$ with compact
support, only finitely many classes $\mathcal O$ have $K_{\mathcal O}(x,x)\neq0$ for some $x\in G(\A)^1$ (\cref{II.kernel.def:class-kernel}).
