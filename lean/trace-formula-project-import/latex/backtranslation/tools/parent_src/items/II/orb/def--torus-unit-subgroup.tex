For $\gamma\in\GL_2(\Q)$ let $U_\gamma\subseteq G_\gamma(\A)^1$ (\cref{II.orb.def:centralizer-norm-one}) be the set of $g$ such that for every prime $p$:
$g_p\in\Qp+\Qp\gamma$, $\tr g_p\in\Zp$ and $\det g_p\in\Zp^\times$. It is a subgroup. If $\Delta(\gamma)=\tr(\gamma)^2-4\det\gamma<0$, it is compact and open in $G_\gamma(\A)^1$;
in terms of $E=\Q(\gamma)$, $U_\gamma=\prod_p\Ocal_{E,p}^\times\times(E_\infty^\times)^1$ with $\Ocal_{E,p}=\Ocal_E\otimes\Zp$.
