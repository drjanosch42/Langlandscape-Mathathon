For every coset $c\in B(\Q)\backslash G(\Q)$ fix a representative $\delta_c\in G(\Q)$, $c=B(\Q)\delta_c$. Let $T\in\aB$ and $\varphi\colon G(\A)^1\to\C$,
with constant term $\varphi_B$ (\texttt{I.cusp.def:constant-term}). The \emph{truncation} of $\varphi$ is the function $\Lambda^T\varphi\colon G(\A)^1\to\C$,
\[
  \Lambda^T\varphi(x)=\varphi(x)-\sum_{c\in B(\Q)\backslash G(\Q)}\varphi_B(\delta_cx)\,\hat\tau_B(\HB(\delta_cx)-T)\qquad(x\in G(\A)^1),
\]
with $\hat\tau_B$ as in \texttt{I.conv.def:chamber-functions}. The sum is the sum of its non-zero terms if there are only finitely many, and $0$ otherwise.
