Let $f\colon G(\A)^1\to\C$, let $B=(B_\mu)_\mu$ be a family of finite sets of functions $G(\A)\to\C$ indexed by the Dirichlet pairs, and let $o$ be a set of Dirichlet pairs. For $x,y\in G(\A)^1$ put
\[
  K_{\mathrm{Eis},o,f}(x,y)=\int_{\R}\sum_{\mu\in o}\ \sum_{\varphi\in B_\mu}\widetilde E\bigl(x,I_\mu(it,f)\varphi,it\bigr)\,\overline{\widetilde E(y,\varphi,it)}\ \frac{\dd t}{4\pi^2},
\]
the Bochner integral (the value $0$ if the integrand is not integrable), where $I_\mu(it,f)$ is the action of $f$ on the induced space \texttt{I.eis.def:induced-rep}. For an orbit $o=\{\mu,w\mu\}$ and a datum $(N,F,B)$ of $f$ this is the Eisenstein part of the orbit kernel $K_{o,f}$ of \cref{II.kernel.def:spectral-kernel}.
