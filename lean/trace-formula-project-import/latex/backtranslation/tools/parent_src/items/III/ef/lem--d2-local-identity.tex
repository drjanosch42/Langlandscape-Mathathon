Let $p$ be a prime, $\chi\in\Z$ and $\nu\in\N$. Define $g,X,Y\colon\N\to\Z$ by
\[
\begin{gathered}
  g(0)=1,\qquad g(j)=p^{j-1}(p-\chi)\quad(j\ge1);\\
  X(0)=\begin{cases}1+\chi&\text{if }\nu=0,\\1&\text{if }\nu\ge1,\end{cases}\qquad X(a)=p+1\quad(a\ge1);\\
  Y(0)=1+\chi,\qquad Y(j)=2\quad(j\ge1).
\end{gathered}
\]
Then
\[
  \sum_{a=0}^{\nu}g(\nu-a)\,X(a)=\sum_{a=0}^{\nu}g(\nu-a)\,Y(\nu-a).
\]
