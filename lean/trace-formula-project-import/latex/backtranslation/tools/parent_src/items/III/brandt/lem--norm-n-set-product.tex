Let $a,b\in\Z$, $\Oord$ an order of $\Bq$ and $m,n\ge1$ coprime. Then $yz\in\Ohat_{mn}$ for $y\in\Ohat_m$ and $z\in\Ohat_n$; every
$w\in\Ohat_{mn}$ is a product $w=yz$ with $y\in\Ohat_m$, $z\in\Ohat_n$; if $y,y'\in\Ohat_m$, $z,z'\in\Ohat_n$ with
$yz\Ohat^\times=y'z'\Ohat^\times$, then $y\Ohat^\times=y'\Ohat^\times$; and the numbers of cosets satisfy
$\abs{\Ohat_{mn}/\Ohat^\times}=\abs{\Ohat_m/\Ohat^\times}\cdot\abs{\Ohat_n/\Ohat^\times}$, where $\abs{\Ohat_n/\Ohat^\times}$ denotes the number of
cosets $y\Ohat^\times$ contained in $\Ohat_n$.
