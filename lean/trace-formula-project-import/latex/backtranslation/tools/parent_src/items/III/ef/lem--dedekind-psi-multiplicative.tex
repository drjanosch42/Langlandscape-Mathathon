Let $\dedpsi$ be the Dedekind function (\cref{III.ef.def:dedekind-psi}).
\begin{enumerate}[label=(\alph*)]
\item For every $N\in\N$, $\dedpsi(N)$ is a natural number.
\item $\dedpsi(N_1N_2)=\dedpsi(N_1)\,\dedpsi(N_2)$ for all coprime $N_1,N_2\in\N$.
\item $\dedpsi(p)=p+1$ for every prime $p$.
\end{enumerate}
