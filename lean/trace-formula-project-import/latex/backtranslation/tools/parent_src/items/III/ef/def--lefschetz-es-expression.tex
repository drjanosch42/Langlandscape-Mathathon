For $N,k,n\in\N$ and a function $F\colon\Z\to\Q$ the \emph{Eichler--Selberg Lefschetz expression} is
\[
\begin{aligned}
  \LamES(N,k,n;F)={}&\delta_{k,2}\,\sigma_1(n)-2\bigl(A_1(N,k,n)+A_2^{\mathrm E}(k,n;F)+A_3(N,k,n)+A_4(k,n)\bigr)\\
  &-\Eis(N,k,n)\in\Q,
\end{aligned}
\]
with $A_1$, $A_2^{\mathrm E}$, $A_3$, $A_4$ and $\Eis$ as in
\cref{III.ef.def:cohen-a1,III.ef.def:eichler-elliptic-expression,III.ef.def:cohen-a3,III.ef.def:cohen-a4,III.ef.def:eisenstein-expression},
$\delta_{k,2}=1$ if $k=2$ and $0$ otherwise, and $\sigma_1(n)$ the sum of the positive divisors of $n$.
