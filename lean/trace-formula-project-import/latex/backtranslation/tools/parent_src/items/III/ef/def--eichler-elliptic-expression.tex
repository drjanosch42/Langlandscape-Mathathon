For $k,n\in\N$ and a function $F\colon\Z\to\Q$ put
\[
  A_2^{\mathrm E}(k,n;F)=-\frac12\sum_{\substack{t\in\Z\\ t^2<4n}}P_k(t,n)\sum_{f\in\Ford(t,n)}\hw(\Delta_f)\,F(\Delta_f)\in\Q,\qquad
  \Delta_f=\frac{t^2-4n}{f^2},
\]
with $P_k$, $\Ford$ and $\hw$ as in \cref{III.ef.def:hecke-polynomial,III.ef.def:order-index-set,III.ef.def:weighted-class-number}.
