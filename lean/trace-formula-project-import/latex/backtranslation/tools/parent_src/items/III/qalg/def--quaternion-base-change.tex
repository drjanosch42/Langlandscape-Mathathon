Let $a,b\in\Z$, let $R$ and $S$ be commutative rings and $f\colon R\to S$ a ring homomorphism. The \emph{base change} along $f$ is the ring homomorphism
\[
  f_{\Bq}\colon\Bq_R(a,b)\to\Bq_S(a,b),\qquad x_0+x_1i+x_2j+x_3k\longmapsto f(x_0)+f(x_1)i+f(x_2)j+f(x_3)k,
\]
applied coordinatewise in the basis $1,i,j,k$ (\cref{III.qalg.def:quaternion-algebra}). For a prime $p$, the map $\Bq\to\Bq_{\Qp}$ is the base change along $\Q\to\Qp$.
