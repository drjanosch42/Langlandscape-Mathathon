Let $a,b\in\Z$ and let $\Oord$ be an order of $\Bq$; for every class $c\in X(\Oord)$ fix a representative $x_c\in\Bhat^\times$. The
\emph{mass} of $\Oord$ is
\[
  \Mass(\Oord)=\sum_{c\in X(\Oord)}\frac1{\abs{\Gamma_{x_c}}}\in\Q,
\]
with the full stabilizers $\Gamma_{x_c}$ of \cref{III.qcls.def:stabilizer} (conventions row N4). Here the sum is $0$ if $X(\Oord)$ is infinite and
$1/\abs{\Gamma}$ is $0$ if $\Gamma$ is infinite; neither happens for $a,b<0$ (\cref{III.qcls.thm:class-set-finite,III.qcls.lem:stabilizer-units}),
and the summands do not depend on the representatives (\cref{III.qcls.lem:stabilizer-units}(b)).
