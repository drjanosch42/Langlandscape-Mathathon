Let $a,b\in\Z$ with $a<0$ and $b<0$, let $\Oord$ be an order of $\Bq$ and $L\subseteq\Bq$ a lattice (a finitely generated $\Z$-submodule with $\Q L=\Bq$) with
$L\Oord\subseteq L$. Then there is $\beta\in L$ with $\beta\ne0$, $\Oord\subseteq\beta^{-1}L$ and
\[
  \pi^2\,[\beta^{-1}L:\Oord]\le8\sqrt{d(\Oord)}.
\]
