Let $a,b\in\Z$. The set $\{x\in\Bq:x_0,x_1,x_2,x_3\in\Z\}$ of elements with integral coordinates in the basis $1,i,j,k$ is a $\Z$-subalgebra of $\Bq$:
it contains $\Z$, is closed under addition, and is closed under products by the multiplication table ($i^2=a$, $j^2=b$, $ij=-ji=k$ with $a,b\in\Z$).
It is the subring $\Z\langle1,i,j,k\rangle$ underlying the standard order of \cref{III.qord.def:standard-order}.
