Let $a,b\in\Z$. The topology of $\Bhat=\Bq_{\Af}$ (\cref{III.qcls.def:finite-adelic-algebra}) is the one induced by the coordinate map
$\Bhat\to\Af^4$, $x\mapsto(x_0,x_1,x_2,x_3)$, from the product topology of $\Af^4$. It is declared on the type of $\Bhat$ itself (a type synonym of
$\Bq_{\Af}$), so that it does not interfere with other topologies on $\Bq_{\Af}$.
