Let $N,f,n\in\N$ and $t\in\Z$. For $N\ge1$ put $N_f=\gcd(N,f)$ and
\[
  \embmu_N(t,f,n)=\frac{\dedpsi(N)}{\dedpsi(N/N_f)}\cdot\#\bigl\{x\in\{0,1,\dots,N-1\}:\ N N_f\mid x^2-tx+n\bigr\}\in\Q,
\]
with $\dedpsi$ the Dedekind function (\cref{III.ef.def:dedekind-psi}); for $N=0$ put $\embmu_0(t,f,n)=0$.
