Let $a,b\in\Z$. For a $\Z$-submodule $L\subseteq\Bq$ (typically a lattice), $\Lhat\subseteq\Bhat$ is the $\Zhat$-submodule spanned by
$\iota(L)$, where $\Bhat$ is a $\Zhat$-module through $\Zhat\subseteq\Af$ (\cref{I.adele.def:zhat}). For an order $\Oord$ of $\Bq$,
\[
  \Ohat^\times=\{u\in\Bhat^\times:u\in\Ohat\text{ and }u^{-1}\in\Ohat\},
\]
a subgroup of $\Bhat^\times$.
