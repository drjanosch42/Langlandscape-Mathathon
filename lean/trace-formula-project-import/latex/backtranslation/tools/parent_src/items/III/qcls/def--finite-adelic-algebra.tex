Let $a,b\in\Z$. The \emph{finite-adelic quaternion algebra} is $\Bhat=\Bq_{\Af}$ (\cref{III.qalg.def:quaternion-algebra} with $R=\Af$,
the finite adeles of \cref{I.adele.def:finite-adeles-model}), with the topology for which the coordinate map $\Bhat\to\Af^4$,
$x\mapsto(x_0,x_1,x_2,x_3)$, is a homeomorphism. We write $\iota\colon\Bq\to\Bhat$ for the base change along the diagonal embedding $\Q\to\Af$.
