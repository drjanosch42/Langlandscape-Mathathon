Let $a,b\in\Z$. The ring $\Bhat=\Bq_{\Af}$ (\cref{III.qcls.def:finite-adelic-algebra}) is an $\Af$-algebra, with $\Af$ acting by scalar multiplication on the four coordinates.
In particular $\Bhat$ is a module over $\Zhat\subseteq\Af$, which gives meaning to $\Lhat$ in \cref{III.qcls.def:order-completion}.
