Let $b\in\Z$ with $b\equiv1\pmod4$ and $a=-1$. The order $\Z\,\tfrac{1+j}2+\Z\,\tfrac{i+k}2+\Z j+\Z k$ of $\Bq(-1,b)$ (Pizer's order; a subring since the
multiplication table of this basis has integral structure constants). For $b=-p$ with $p\equiv3\pmod4$ prime this is Pizer's maximal order; $\Oord_{11}$ of
\cref{III.qcls.ex:eichler-mass-instance-d11} is the case $b=-11$.
