For $N,k,n\in\N$ put
\[
  A_1(N,k,n)=\begin{cases}\dfrac{k-1}{12}\,\dedpsi(N)\,r^{k-2}&\text{if }n=r^2\text{ with }r\in\N,\\[1ex] 0&\text{if $n$ is not a square,}\end{cases}
\]
an element of $\Q$, where $\dedpsi$ is the Dedekind function (\cref{III.ef.def:dedekind-psi}), $k-1$ is computed in $\Q$, and the exponent $k-2$ is
read as $\max(k-2,0)$.
