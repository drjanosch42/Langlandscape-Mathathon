Let $a,b\in\Z$ with $a<0$ and $b<0$, let $\Oord$ be an order of $\Bq$, $M\ge1$, and $\phi$ a level structure of level $M$ on $\Oord$
(\cref{III.qord.def:level-structure}), with Eichler order $\Oord(M;\phi)$ (\cref{III.qord.def:eichler-order}). Then
\[
  \bigl[\Ohat^\times:\widehat{\Oord(M;\phi)}^\times\bigr]=\dedpsi(M)\qquad\text{and}\qquad\Mass(\Oord(M;\phi))=\dedpsi(M)\,\Mass(\Oord).
\]
