Let $a,b\in\Z$, $\Oord$ an order of $\Bq$, $K$ a field of characteristic $0$, $s$ a splitting of $\Bq$ over $K$ and $k\in\N$. Let
$(x_c)_{c\in X(\Oord)}$ be elements of $\Bhat^\times$ with $[x_c]=c$. Then $f\mapsto(f(x_c))_c$ is a $K$-linear isomorphism
\[
  M_k(\Oord;s)\;\xrightarrow{\ \sim\ }\;\prod_{c\in X(\Oord)}V_{k-2}(K)^{\Gamma_{x_c}},\qquad
  V_{k-2}(K)^{\Gamma}=\{v:\rho_k^s(\gamma)v=v\text{ for all }\gamma\in\Gamma\}.
\]
