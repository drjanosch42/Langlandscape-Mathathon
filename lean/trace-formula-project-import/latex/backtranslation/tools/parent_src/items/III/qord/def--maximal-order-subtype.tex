Let $a,b\in\Z$. The type $\operatorname{MaxOrder}(a,b)$ is the type of pairs $(\Oord,h)$ of an order $\Oord$ of $\Bq$ and a proof $h$ that $\Oord$ is maximal
(\cref{III.qord.def:maximal-order}); it is the set of maximal orders of $\Bq$, used as the type of the order argument of H-EM
(\cref{III.qcls.hyp:eichler-mass}) and of \cref{III.qcls.cor:eichler-order-mass}.
