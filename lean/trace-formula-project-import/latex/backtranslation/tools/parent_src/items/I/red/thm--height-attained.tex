Let $x\in G(\A)$. Then $\lambda(x)>0$, and there is $\delta_0\in G(\Q)$ with $\norm{e_2\delta_0x}_\A=\lambda(x)$. For every
such $\delta_0$,
\[
  \operatorname{ht}(x)=\alpha(\HB(\delta_0x))=\max_{\delta\in G(\Q)}\alpha(\HB(\delta x)).
\]
Moreover $\operatorname{ht}(\gamma xk)=\operatorname{ht}(x)$ for all $\gamma\in G(\Q)$ and $k\in K$.
