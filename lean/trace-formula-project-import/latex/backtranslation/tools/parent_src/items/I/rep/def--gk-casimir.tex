For a $(\mathfrak g,\Kinf)$-module $V$ the Casimir $\Delta=-\frac14(A^2+2EF+2FE)$ is the linear endomorphism of $V$ given by the action of the same expression in the Lie algebra as in \cref{I.rep.def:casimir}, with $A=\mathrm{diag}(1,-1)$, $E=\begin{psmallmatrix}0&1\\0&0\end{psmallmatrix}$ and $F=\begin{psmallmatrix}0&0\\1&0\end{psmallmatrix}$.
