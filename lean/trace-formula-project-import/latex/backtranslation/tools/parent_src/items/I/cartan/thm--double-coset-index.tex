Let $F$ be a non-archimedean local field with residue cardinality $q$, let $a\ge b$ be integers and $n=a-b$. The set
$\{hK_F:h\in K_F\,t_{a,b}\,K_F\}\subseteq\GL_2(F)/K_F$ of left cosets of $K_F$ contained in $K_F\,t_{a,b}\,K_F$ is
finite. It has exactly one element if $n=0$, and exactly $q^n+q^{n-1}$ elements if $n\ge1$.
