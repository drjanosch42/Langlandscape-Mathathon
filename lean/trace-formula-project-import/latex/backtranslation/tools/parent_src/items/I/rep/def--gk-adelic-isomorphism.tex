Let $V$ and $V'$ be $(\mathfrak g,\Kinf)\times G(\Af)$-modules (\cref{I.rep.def:gk-finite-adelic-module}) with Lie
actions $X\cdot v$, $X\cdot'v'$, $\Kinf$-actions $\kappa$, $\kappa'$ and $G(\Af)$-actions $\sigma_f$, $\sigma_f'$. They are
\emph{isomorphic} if there is a $\C$-linear bijection $T\colon V\to V'$ with $T(X\cdot v)=X\cdot'T(v)$,
$T(\kappa(k)v)=\kappa'(k)T(v)$ and $T(\sigma_f(h)v)=\sigma_f'(h)T(v)$ for all $X\in\mathfrak g$, $k\in\Kinf$,
$h\in G(\Af)$ and $v\in V$.
