Let $\dd k$ be the Haar probability measure of $\Kinf=\Ort(2)$. For every Borel function
$f\colon\GL_2(\R)\to[0,\infty]$ and for every $\dd g_\infty$-integrable $f\colon\GL_2(\R)\to\C$,
\[
  \int_{\GL_2(\R)}f\,\dd g_\infty=\pi\int_\R\int_{\R^\times}\int_{\R^\times}\int_{\Ort(2)}
  f\bigl(n(x)\diag(t_1,t_2)k\bigr)\,\abs{t_1/t_2}^{-1}\,\dd k\,\frac{\dd t_1}{\abs{t_1}}\,\frac{\dd t_2}{\abs{t_2}}\,\dd x .
\]
