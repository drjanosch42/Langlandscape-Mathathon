We write $B(\A)$, $T(\A)$, $N(\A)$, $Z(\A)$ for the subgroups $B(R)$, $T(R)$, $N(R)$, $Z(R)$ of $G(\A)$ for $R=\A$
(\cref{I.conv.def:borel,I.conv.def:torus,I.conv.def:unipotent,I.conv.def:center}), and likewise for $R=\Af$. Moreover
\[
  T(\A)^1=\{\diag(t_1,t_2)\in T(\A):\abs{t_1}_\A=\abs{t_2}_\A=1\}.
\]
