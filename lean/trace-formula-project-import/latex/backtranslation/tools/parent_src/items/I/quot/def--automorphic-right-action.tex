The group $G(\A)^1$ acts on $G(\Q)\backslash G(\A)^1$ from the right by $(G(\Q)x)\cdot g=G(\Q)xg$. This is a well-defined
continuous right action, and for every left Haar measure $\mu$ on $G(\A)$ the measure of
\cref{I.quot.def:automorphic-quotient-measure} is invariant under it: $\vol(E\cdot g)=\vol(E)$ for every Borel set
$E\subseteq G(\Q)\backslash G(\A)^1$ and every $g\in G(\A)^1$.
