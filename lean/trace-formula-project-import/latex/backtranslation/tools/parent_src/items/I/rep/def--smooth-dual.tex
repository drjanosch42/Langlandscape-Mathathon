For a representation $(\pi,V)$ of $G$, let $\pi^*(g)\lambda=\lambda\circ\pi(g^{-1})$ be the dual representation on the algebraic dual $V^*$. The space $\tilde V\subseteq V^*$ of smooth vectors consists of the $\lambda$ whose stabilizer $\{g\in G:\pi^*(g)\lambda=\lambda\}$ is open; it is a $\C$-subspace.
