Let $G$ be a topological group, $V$ a complex vector space and $\pi\colon G\to\GL(V)$ a representation (a group
homomorphism into the $\C$-linear automorphisms of $V$). For a subgroup $K'\subseteq G$ write
$V^{K'}=\{v\in V:\pi(k)v=v\text{ for all }k\in K'\}$. The representation $\pi$ is \emph{smooth} if for every
$v\in V$ the stabilizer $\{g\in G:\pi(g)v=v\}$ is an open subset of $G$.
