Take Fourier transforms with respect to the standard Haar measure $\dd x$. For $\Phi\in\Schw(\A)$ we have
$\hat\Phi\in\Schw(\A)$ and $\hat{\hat\Phi}(x)=\Phi(-x)$ for all $x\in\A$. Moreover, for factorizable
$\Phi=\Phi_\infty\otimes\bigotimes_p\Phi_p$, $\hat\Phi=\hat\Phi_\infty\otimes\bigotimes_p\hat\Phi_p$, where
$\hat\Phi_\infty(t)=\int_\R\Phi_\infty(u)e^{-2\pi iut}\,\dd u$ and $\hat\Phi_p$ is taken with respect to $(\psi_p,\dd x_p)$.
