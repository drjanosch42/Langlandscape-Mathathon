The \emph{standard character} of $\A$ is $\psi\colon\A\to\C^\times$,
\[
  \psi(x)=e^{-2\pi ix_\infty}\prod_p\psi_p(x_p),
\]
where all but finitely many factors equal $1$ (as $\psi_p=1$ on $\Zp$). It is a continuous homomorphism from the additive
group of $\A$ to the unit circle. We write $\psi_\infty(t)=e^{-2\pi it}$ for $t\in\R$.
