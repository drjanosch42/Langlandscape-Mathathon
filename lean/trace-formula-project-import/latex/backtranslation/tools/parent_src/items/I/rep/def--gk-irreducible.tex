Let $V$ be a $(\mathfrak g,\Kinf)$-module (\cref{I.rep.def:gk-module}) with Lie action $(X,v)\mapsto X\cdot v$ and
$\Kinf$-action $\kappa$. A \emph{$(\mathfrak g,\Kinf)$-submodule} of $V$ is a $\C$-linear subspace $W\subseteq V$ with
$X\cdot w\in W$ and $\kappa(k)w\in W$ for all $X\in\mathfrak g$, $k\in\Kinf$ and $w\in W$. The module $V$ is
\emph{irreducible} if $V\neq0$ and its only $(\mathfrak g,\Kinf)$-submodules are $0$ and $V$.
