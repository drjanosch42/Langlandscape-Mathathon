The \emph{Schwartz--Bruhat space} $\Schw(\A)$ is the $\C$-linear span of the functions
\[
  x\longmapsto\Phi_\infty(x_\infty)\prod_p\Phi_p(x_p)
\]
on $\A$, where $\Phi_\infty\colon\R\to\C$ is a Schwartz function, $\Phi_p\in\Schw(\Qp)$ for every prime $p$, and
$\Phi_p=1_{\Zp}$ for all but finitely many $p$ (so that all but finitely many factors equal $1$). Such a function is
written $\Phi_\infty\otimes\bigotimes_p\Phi_p$ and called \emph{factorizable}.
