For $g\in G(\A)$ with bottom row $(c,d)\in\A^2$ put
\[
  \norm{e_2g}_\A=\bigl(c_\infty^2+d_\infty^2\bigr)^{1/2}\prod_p\max\bigl(\abs{c_p}_{\Qp},\abs{d_p}_{\Qp}\bigr),
\]
where all factors are positive and all but finitely many equal $1$. The \emph{height map} $\HB\colon G(\A)\to\aB$ is
\[
  \HB(g)=\bigl(\log\abs{\det g}_\A-\log\norm{e_2g}_\A,\ \log\norm{e_2g}_\A\bigr).
\]
