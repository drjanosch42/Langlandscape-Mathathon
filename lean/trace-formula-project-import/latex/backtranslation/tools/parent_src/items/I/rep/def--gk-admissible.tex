Let $V$ be a $(\mathfrak g,\Kinf)$-module, and for $v\in V$ put
$\Delta v=-\frac14\bigl(A\cdot(A\cdot v)+2\,E\cdot(F\cdot v)+2\,F\cdot(E\cdot v)\bigr)$ and $Zv=1\cdot v$, with $A,E,F$ as
in \cref{I.rep.def:casimir}. For $n\in\Z$ let $V_n=\{v\in V:\kappa(k_\theta)v=e^{in\theta}v\text{ for all }\theta\in\R\}$.
The module $V$ is \emph{admissible and $(\Delta,Z)$-finite} if $V_n$ is finite-dimensional for every $n\in\Z$, and
for every $v\in V$ the span of $\{\Delta^aZ^bv:a,b\ge0\}$ is finite-dimensional.
