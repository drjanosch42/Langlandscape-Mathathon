Let $V$ and $V'$ be $(\mathfrak g,\Kinf)$-modules (\cref{I.rep.def:gk-module}) with Lie actions $X\cdot v$, $X\cdot'v'$
and $\Kinf$-actions $\kappa$, $\kappa'$. They are \emph{isomorphic} if there is a $\C$-linear bijection $T\colon V\to V'$
with $T(X\cdot v)=X\cdot'T(v)$ and $T(\kappa(k)v)=\kappa'(k)T(v)$ for all $X\in\mathfrak g$, $k\in\Kinf$ and $v\in V$.
