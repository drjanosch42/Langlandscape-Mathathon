The \emph{standard Haar measure} $\dd x$ on $\A$ is the product of the Lebesgue measure $\dd x_\infty$ on $\R$ and the
restricted-product measure $\dd x_f=\bigotimes'_p\dd x_p$ on $\Af$ (\cref{X.haar.def:restricted-product-measure}),
where $\dd x_p$ is the normalized additive Haar measure of $\Qp$, so that $\dd x_f(\Zhat)=1$. It is a Haar measure on the
additive group of $\A$.
