Let $F$ be a non-archimedean local field, $G=\GL_2(F)$, $w$ the Weyl element, and $\dd x$ the normalized additive Haar
measure on $F$. For a function $f\colon G\to\C$ the function $M(w)f\colon G\to\C$ is
\[
  (M(w)f)(g)=\int_Ff\bigl(w\,n(x)\,g\bigr)\,\dd x ,
\]
where the integral is the Bochner integral, which is $0$ by convention when $x\mapsto f(w\,n(x)\,g)$ is not integrable.
