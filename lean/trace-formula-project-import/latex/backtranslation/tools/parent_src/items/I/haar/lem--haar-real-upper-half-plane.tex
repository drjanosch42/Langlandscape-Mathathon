Let $\dd g_\infty$ be the standard Haar measure on $\GL_2(\R)$ (\cref{I.haar.def:haar-real}), $\dd k$ the Haar probability
measure of $\Kinf=\Ort(2)$ (\cref{I.haar.def:haar-orthogonal}) and $G(\R)^1=\{g\in\GL_2(\R):\abs{\det g}=1\}$. For Borel
$E\subseteq G(\R)^1$ put
\[
  m_\infty(E)=\dd g_\infty\bigl(\{rg:1\le r<e,\ g\in E\}\bigr).
\]
Then $m_\infty$ is a Borel measure on $G(\R)^1$, and for every Borel function $F\colon G(\R)^1\to[0,\infty]$
\[
  \int_{G(\R)^1}F\,\dd m_\infty=4\pi\int_\R\int_0^\infty\int_{\Ort(2)}F\bigl(n(x)\diag(y^{1/2},y^{-1/2})\,k\bigr)\,\dd k\,\frac{\dd y}{y^2}\,\dd x .
\]
