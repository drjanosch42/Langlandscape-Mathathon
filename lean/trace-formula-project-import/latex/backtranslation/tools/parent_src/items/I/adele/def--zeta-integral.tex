Let $\nu$ be a Haar measure on $\A^\times$, $\Phi\colon\A\to\C$, $\chi$ a Hecke character and $s\in\C$. The
\emph{zeta integral} is
\[
  Z(s,\Phi,\chi;\nu)=\int_{\A^\times}\Phi(t)\,\chi(t)\,\abs{t}_\A^{s}\,\dd\nu(t),
\]
where $\Phi(t)$ is the value of $\Phi$ at the adele $t$ and $\abs{t}_\A^s=\exp(s\log\abs{t}_\A)$. The integral is the
Bochner integral; it is $0$ if the integrand is not $\nu$-integrable.
