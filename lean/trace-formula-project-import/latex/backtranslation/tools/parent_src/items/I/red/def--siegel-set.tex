For $t_0>0$ let $A(t_0)\subseteq T(\A)$ be the set of $a\in T(\A)$ with $a_\infty=\diag(a_1,a_2)$, where
$a_1,a_2>0$, $a_1a_2=1$ and $a_1/a_2\ge t_0$, and $a_p=1$ for every prime $p$. For a subset $\omega\subseteq N(\A)$ the
\emph{Siegel set} is
\[
  \mathfrak S(\omega,t_0)=\{nak:n\in\omega,\ a\in A(t_0),\ k\in K\}\subseteq G(\A).
\]
It is contained in $G(\A)^1$.
