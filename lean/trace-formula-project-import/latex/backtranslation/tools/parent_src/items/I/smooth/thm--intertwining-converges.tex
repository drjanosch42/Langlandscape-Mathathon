Let $F$ be a non-archimedean local field with uniformizer $\unif$, $G=\GL_2(F)$, and let $\chi_1,\chi_2$ be
quasi-characters of $F^\times$ with $\abs{\chi_1(\unif)\chi_2(\unif)^{-1}}<1$. Then for every $f\in I(\chi_1,\chi_2)$ and
every $g\in G$ the function $x\mapsto f(w\,n(x)\,g)$ is integrable on $F$ for the normalized additive Haar measure
$\dd x$, and $M(w)f\in I(\chi_2,\chi_1)$.
