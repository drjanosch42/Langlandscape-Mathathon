Let $G$ be a locally profinite group with its Borel $\sigma$-algebra, $\mu$ a left Haar measure on $G$, and $\pi$ a
smooth representation of $G$ on a complex vector space $V$. For $f\in C_c^\infty(G)$ and $v\in V$ the function
$\varphi\colon G\to V$, $\varphi(g)=f(g)\pi(g)v$, takes only finitely many values, and for each non-zero value $u$ the
set $\varphi^{-1}(u)$ is a Borel set of finite measure. We put
\[
  \pi(f)v=\int_Gf(g)\,\pi(g)v\,\dd\mu(g)=\sum_{u\in\varphi(G)\setminus\{0\}}\mu\bigl(\varphi^{-1}(u)\bigr)\,u .
\]
