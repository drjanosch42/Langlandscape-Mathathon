For every continuous homomorphism $\chi_0\colon\Zhat^\times\to\C^\times$ and every $s\in\C$, the function
$x\mapsto\chi_0(u(x))\,\abs{x}_\A^{s}$ (with $u(x)$ as in \cref{I.adele.thm:idele-decomposition}) is a Hecke character.
Conversely, every Hecke character $\chi$ is of this form for a unique pair $(\chi_0,s)$, namely
$\chi_0(u)=\chi((1,u))$ and $s$ determined by $\chi((r,1))=r^s$ for $r>0$. So $\chi\mapsto(\chi_0,s)$ is a bijection from
the Hecke characters onto the set of pairs $(\chi_0,s)$.
