Let $G$ be a topological group and $\mathcal H$ a complex Hilbert space, with unitary group
$\mathrm U(\mathcal H)$ (the bounded linear operators $T$ with $T^*T=TT^*=1$). A \emph{unitary representation} of $G$
on $\mathcal H$ is a group homomorphism $\pi\colon G\to\mathrm U(\mathcal H)$. It is \emph{strongly continuous} if for
every $v\in\mathcal H$ the map $G\to\mathcal H$, $g\mapsto\pi(g)v$, is continuous.
