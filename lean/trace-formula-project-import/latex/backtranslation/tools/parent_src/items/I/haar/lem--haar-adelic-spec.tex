Let $\mu_\infty$ be a Haar measure on $\GL_2(\R)$ and $\mu_p$ Haar measures on $\GL_2(\Qp)$ with $\mu_p(K_p)=1$ for all but finitely many $p$. Then $\dd g_f=\bigotimes'_p\mu_p$ is a Haar measure on $G(\Af)$, $\dd g=\mu_\infty\otimes\dd g_f$ is a Haar measure on $G(\A)$, and $\dd g_f(K_f)=\prod_p\mu_p(K_p)$.
