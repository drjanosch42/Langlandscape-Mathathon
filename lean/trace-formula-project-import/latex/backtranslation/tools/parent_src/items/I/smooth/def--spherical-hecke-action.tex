Let $F$ be a non-archimedean local field, $G=\GL_2(F)$, $K=K_F$, and let $\pi$ be a representation of $G$ on a complex
vector space $V$. For $f\in\mathcal H(G,K)$ and $v\in V^K$ put
\[
  \pi(f)v=\sum_{gK\in G/K}f(g)\,\pi(g)v .
\]
The summand depends only on the coset $gK$ and vanishes for all but finitely many cosets, and $\pi(f)v\in V^K$; so
$\pi(f)$ is a $\C$-linear endomorphism of $V^K$, depending $\C$-linearly on $f$.
