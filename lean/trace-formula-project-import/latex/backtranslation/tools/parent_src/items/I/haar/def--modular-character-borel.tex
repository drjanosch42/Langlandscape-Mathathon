Let $R$ be a commutative ring and $\abs{\cdot}\colon R^\times\to\R_{>0}$ a group homomorphism. The \emph{modular
character} of $B(R)$ is
\[
  \deltaB\colon B(R)\to\R_{>0},\qquad\deltaB(b)=\abs{b_{11}}\,\abs{b_{22}}^{-1}.
\]
For $b=n(x)\diag(t_1,t_2)$ this is $\deltaB(b)=\abs{t_1/t_2}$. We use it for $R=F$ a non-archimedean local field with
$\abs{\cdot}_F$, for $R=\R$ with the usual absolute value, and for $R=\A$ (and $\Af$) with the idele norm.
