The \emph{standard Haar measure} $\dd g_\infty$ on $\GL_2(\R)$ is $\abs{\det g}^{-2}\dd X$:
\[
  \dd g_\infty(E)=\int_E\abs{\det g}^{-2}\,\dd X(g)\qquad(E\subseteq\GL_2(\R)\text{ Borel}),
\]
where $\dd X$ is the Lebesgue measure of $\Mat_2(\R)\cong\R^4$ and $\GL_2(\R)$ is viewed as the open subset
$\{\det\neq0\}$ of $\Mat_2(\R)$.
