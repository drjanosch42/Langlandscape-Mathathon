For a commutative ring $R$ we write $G(R)=\GL_2(R)=\Mat_2(R)^\times$ for the group of invertible $2\times2$ matrices
over $R$. A ring homomorphism $f\colon R\to R'$ of commutative rings induces the map
$f_*\colon\GL_2(R)\to\GL_2(R')$ obtained by applying $f$ to every matrix entry, $(f_*g)_{ij}=f(g_{ij})$; it is a group
homomorphism.
