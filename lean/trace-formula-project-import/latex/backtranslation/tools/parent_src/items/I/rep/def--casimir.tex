Let $A=\begin{psmallmatrix}1&0\\0&-1\end{psmallmatrix}$, $E=\begin{psmallmatrix}0&1\\0&0\end{psmallmatrix}$,
$F=\begin{psmallmatrix}0&0\\1&0\end{psmallmatrix}$ and let $1$ be the identity matrix. For $f\in C^\infty(\GL_2(\R))$
the \emph{Casimir operator} $\Delta$ and the \emph{central operator} $Z$ are
\[
  \Delta f=-\tfrac14\bigl(A\cdot(A\cdot f)+2\,E\cdot(F\cdot f)+2\,F\cdot(E\cdot f)\bigr),\qquad Zf=1\cdot f .
\]
