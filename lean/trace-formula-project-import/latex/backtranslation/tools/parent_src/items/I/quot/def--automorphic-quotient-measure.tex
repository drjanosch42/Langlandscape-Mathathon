$G(\Q)$ is a discrete subgroup of $G(\A)^1$. For a left Haar measure $\mu$ on $G(\A)$, the measure on
$G(\Q)\backslash G(\A)^1$ is the quotient measure $(\mu^1)_{G(\Q)\backslash G(\A)^1}$ of the measure $\mu^1$ of
\cref{I.haar.def:haar-norm-one} (\cref{X.quot.def:quotient-measure}). For $\mu=\dd g$ we write $\dd\dot g$.
