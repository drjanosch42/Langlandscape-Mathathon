Let $F$ be a non-archimedean local field with uniformizer $\unif$ and residue cardinality $q$. For an unramified
quasi-character $\mu$ of $F^\times$ and $s\in\C$ put
\[
  L(s,\mu)=\bigl(1-\mu(\unif)\,q^{-s}\bigr)^{-1}\quad\text{if }\mu(\unif)\,q^{-s}\neq1,\qquad L(s,\mu)=0\quad\text{otherwise},
\]
where $q^{-s}=e^{-s\log q}$.
