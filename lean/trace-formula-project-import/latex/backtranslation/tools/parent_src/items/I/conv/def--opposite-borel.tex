Let $R$ be a commutative ring. The \emph{opposite Borel subgroup} $\Bbar(R)\subseteq\GL_2(R)$ is the set of lower
triangular invertible matrices, $\Bbar(R)=\{g\in\GL_2(R):g_{12}=0\}$. For $x\in R$ let
$\bar n(x)=\begin{psmallmatrix}1&0\\x&1\end{psmallmatrix}\in\GL_2(R)$; the \emph{opposite unipotent subgroup} is
$\Nbar(R)=\{\bar n(x):x\in R\}$. Both are subgroups of $\GL_2(R)$, and $\bar n\colon R\to\GL_2(R)$ is an injective
group homomorphism from the additive group of $R$ with image $\Nbar(R)$.
