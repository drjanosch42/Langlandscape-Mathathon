Let $F$ be a non-archimedean local field, $\psi\colon F\to\C^\times$ a continuous homomorphism from the additive group
of $F$ to the unit circle, and $\mu$ an additive Haar measure on $F$. The \emph{Fourier transform} of
$\Phi\colon F\to\C$ with respect to $(\psi,\mu)$ is
\[
  \hat\Phi(y)=\int_F\Phi(x)\,\psi(xy)\,\dd\mu(x)\qquad(y\in F).
\]
