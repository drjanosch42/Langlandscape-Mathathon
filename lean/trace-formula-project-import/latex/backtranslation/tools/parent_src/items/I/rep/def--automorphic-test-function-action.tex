Let $\mu$ be a left Haar measure on $G(\A)$ and $f\colon G(\A)^1\to\C$ continuous with compact support. Then
$R(f)$ is the operator $\pi(f)$ of \cref{I.rep.def:integrated-rep} for the group $G(\A)^1$, its Haar measure $\mu^1$
(\cref{I.haar.def:haar-norm-one}) and $\pi=R$ (\cref{I.rep.def:automorphic-regular-rep}):
\[
  R(f)\varphi=\int_{G(\A)^1}f(y)\,R(y)\varphi\,\dd\mu^1(y)\qquad(\varphi\in\Ltwo(G(\Q)\backslash G(\A)^1)).
\]
It is a bounded linear operator with $\norm{R(f)}\le\int\abs f\,\dd\mu^1$.
