Let $\mathcal D=\{z\in\C:\operatorname{Im}z>0,\ \abs z\ge1,\ \abs{\operatorname{Re}z}\le\tfrac12\}$ and
$\mathcal D'=\{z\in\mathcal D:\operatorname{Re}z\ge0\}$. With $z=x+iy$ and the Lebesgue measure $\dd x\,\dd y$ of $\C=\R^2$,
\[
  \int_{\mathcal D}\frac{\dd x\,\dd y}{y^2}=\frac\pi3,\qquad\int_{\mathcal D'}\frac{\dd x\,\dd y}{y^2}=\frac\pi6.
\]
