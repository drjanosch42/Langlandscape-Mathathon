Let $\nu$ be a Haar measure on $\A^\times$, $\Phi\in\Schw(\A)$, $\chi$ a Hecke character and $s\in\C$ with
$\operatorname{Re}s+\operatorname{Re}\sigma(\chi)>1$. Then $t\mapsto\Phi(t)\chi(t)\abs{t}_\A^s$ is $\nu$-integrable on
$\A^\times$. In particular, for unitary $\chi$ this holds for $\operatorname{Re}s>1$.
