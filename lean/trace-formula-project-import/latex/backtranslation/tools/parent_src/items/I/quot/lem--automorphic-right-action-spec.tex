The right action of $G(\A)^1$ on $G(\Q)\backslash G(\A)^1$ of \cref{I.quot.def:automorphic-right-action} satisfies: (i) $(G(\Q)x)\cdot g=G(\Q)xg$; (ii) it is continuous; (iii) the quotient $\sigma$-algebra is the Borel $\sigma$-algebra; (iv) for every left Haar measure $\mu$ on $G(\A)$, every Borel set $E$ and every $g\in G(\A)^1$, $\vol(E\cdot g)=\vol(E)$ for the measure of \cref{I.quot.def:automorphic-quotient-measure}.
