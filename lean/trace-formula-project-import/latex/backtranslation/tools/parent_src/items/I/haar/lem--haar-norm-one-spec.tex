Let $\mu$ be a Haar measure on $G(\A)$. Then $\mu^1(E)=\mu(\{a(r)g:1\le r<e,\ g\in E\})$ for measurable $E\subseteq G(\A)^1$; $\mu^1$ is a Haar measure on $G(\A)^1$; and under every isomorphism of topological groups $\AGplus\times G(\A)^1\to G(\A)$, $(a,g)\mapsto ag$ (\cref{I.topgrp.thm:norm-one-splitting}), $\mu$ corresponds to $\dd r/r\otimes\mu^1$.
