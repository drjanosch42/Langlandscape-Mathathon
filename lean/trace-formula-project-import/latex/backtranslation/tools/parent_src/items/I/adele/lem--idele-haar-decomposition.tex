Let $\nu$ be a Haar measure on $\A^\times$, let $\dd u$ be the Haar probability measure of the compact group
$\Zhat^\times$, and put
\[
  \kappa(\nu)=\nu\bigl(\{x\in\A^\times:x_\infty\in[1,e),\ x_p\in\Zp^\times\text{ for all }p\}\bigr).
\]
Then $0<\kappa(\nu)<\infty$, and for every Borel function $f\colon\A^\times\to[0,\infty]$
\[
  \int_{\A^\times}f\,\dd\nu=\kappa(\nu)\sum_{q\in\Q^\times}\int_0^\infty\int_{\Zhat^\times}f\bigl(q\cdot(r,u)\bigr)\,\dd u\,
  \frac{\dd r}{r}.
\]
The same formula holds for every $\nu$-integrable $f\colon\A^\times\to\C$, the series converging absolutely.
