A \emph{$(\mathfrak g,\Kinf)\times G(\Af)$-module} is a $(\mathfrak g,\Kinf)$-module $V$ (\cref{I.rep.def:gk-module}), with
Lie action $(X,v)\mapsto X\cdot v$ and $\Kinf$-action $\kappa$, together with a smooth representation
$\sigma_f\colon G(\Af)\to\GL(V)$ (\cref{I.rep.def:smooth-rep}) such that
\[
  \sigma_f(h)(X\cdot v)=X\cdot\sigma_f(h)v,\qquad \sigma_f(h)\kappa(k)v=\kappa(k)\sigma_f(h)v
\]
for all $h\in G(\Af)$, $X\in\mathfrak g$, $k\in\Kinf$ and $v\in V$.
