Let $f\in C^\infty(\GL_2(\R))$ and $\tilde f$ as in \cref{I.hecke.def:smooth-function-real}. For
$X\in\Mat_2(\R)$ the function $X\cdot f\colon\GL_2(\R)\to\C$ is
\[
  (X\cdot f)(g)=D\tilde f(g)(gX),
\]
the derivative of $\tilde f$ at the point $g\in U$ in the direction of the matrix $gX$. For $X\in\Mat_2(\C)$ write
$X=X_1+iX_2$ with $X_1,X_2\in\Mat_2(\R)$ (entrywise real and imaginary parts) and put
$X\cdot f=X_1\cdot f+i\,X_2\cdot f$.
