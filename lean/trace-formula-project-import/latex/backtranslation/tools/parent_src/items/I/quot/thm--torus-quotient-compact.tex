$T(\Q)=\{\diag(q_1,q_2):q_1,q_2\in\Q^\times\}$ is a discrete subgroup of $T(\A)^1$, and the map
$\diag(t_1,t_2)\mapsto(t_1,t_2)$ is an isomorphism of topological groups $T(\A)^1\to\A^1\times\A^1$ carrying $T(\Q)$
onto $\Q^\times\times\Q^\times$. Consequently $\diag(t_1,t_2)\mapsto(u(t_1),u(t_2))$ (with $u$ as in
\cref{I.adele.thm:idele-decomposition}) induces an isomorphism of topological groups
$T(\Q)\backslash T(\A)^1\cong\Zhat^\times\times\Zhat^\times$; in particular $T(\Q)\backslash T(\A)^1$ is compact.
