$B(\Q)=B(\A)\cap G(\Q)$ is a discrete subgroup of $G(\A)$. Let $\dd g$, $\lambda$, $\nu$, $\dd k$ and $c$ be as in
\cref{I.haar.thm:iwasawa-integration}, let $D=[0,1)\times\Zhat\subseteq\A$ and
$D_T=\{\diag(t_1,t_2):t_1,t_2\in\R_{>0}\times\Zhat^\times\}\subseteq T(\A)$. Then for every Borel function
$\varphi\colon B(\Q)\backslash G(\A)\to[0,\infty]$, viewed as a left $B(\Q)$-invariant function on $G(\A)$,
\[
  \int_{B(\Q)\backslash G(\A)}\varphi\,\dd g_{B(\Q)\backslash G(\A)}
  =c\int_{D_T}\int_D\int_K\varphi\bigl(n(x)\,t\,k\bigr)\,\deltaB(t)^{-1}\,\dd k\,\dd\lambda(x)\,\dd t,
\]
where $\dd t$ is the image of $\nu\otimes\nu$ on $T(\A)$ and $\deltaB(t)=\abs{t_1/t_2}_\A$.
