Let $\nu$ be a Haar measure on $\A^\times$, $\Phi\in\Schw(\A)$ and $\chi$ a Hecke character. Then:
\begin{enumerate}
\item $Z(s,\Phi,\chi;\nu)=Z^*(s,\Phi,\chi;\nu)$ for every $s\in\C$ with $\operatorname{Re}s+\operatorname{Re}\sigma(\chi)>1$;
\item $s\mapsto Z^*(s,\Phi,\chi;\nu)$ is holomorphic on $\C\setminus\{-\sigma(\chi),1-\sigma(\chi)\}$;
\item if $\omega_\chi$ is non-trivial, $s\mapsto Z^*(s,\Phi,\chi;\nu)$ is entire.
\end{enumerate}
