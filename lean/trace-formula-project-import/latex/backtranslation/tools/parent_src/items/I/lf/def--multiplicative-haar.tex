Let $F$ be a non-archimedean local field with residue cardinality $q$. The \emph{normalized multiplicative Haar
measure} $\dtimes x$ on $F^\times$ is
\[
  \dtimes x(E)=\frac1{1-q^{-1}}\int_E\abs{x}_F^{-1}\,\dd x\qquad(E\subseteq F^\times\text{ Borel}),
\]
where $\dd x$ is the normalized additive Haar measure; it is a Haar measure on the locally compact group $F^\times$.
