Let $F$ be a non-archimedean local field, $\mu$ a left Haar measure on $\GL_2(F)$, $\lambda$ an additive Haar measure
on $F$, $\nu$ a Haar measure on $F^\times$, and $\dd k$ the Haar probability measure of $K_F$. Put
\[
  c_F=\frac{\mu(K_F)}{\lambda(\Ocal_F)\,\nu(\Ocal_F^\times)^2}.
\]
Then for every Borel function $f\colon\GL_2(F)\to[0,\infty]$ and for every $\mu$-integrable $f\colon\GL_2(F)\to\C$,
\[
  \int_{\GL_2(F)}f\,\dd\mu=c_F\int_F\int_{F^\times}\int_{F^\times}\int_{K_F}
  f\bigl(n(x)\diag(t_1,t_2)k\bigr)\,\abs{t_1/t_2}_F^{-1}\,\dd k\,\dd\nu(t_1)\,\dd\nu(t_2)\,\dd\lambda(x).
\]
