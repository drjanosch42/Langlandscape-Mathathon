For $g\in G(\A)$ let $\norm{e_2g}_\A$ be the norm of the bottom row of $g$ (\cref{I.decomp.def:height-map}). For
$x\in G(\A)$ put
\[
  \lambda(x)=\inf_{\delta\in G(\Q)}\norm{e_2\delta x}_\A\in[0,\infty),\qquad
  \operatorname{ht}(x)=\log\abs{\det x}_\A-2\log\lambda(x),
\]
with the convention $\log0=0$ (\cref{I.red.thm:height-attained} shows $\lambda(x)>0$).
