Let $G$ be a topological group, $X$ a topological space with its Borel $\sigma$-algebra and a continuous right action
$X\times G\to X$, $(x,g)\mapsto x\cdot g$, and $\nu$ a measure on $X$ that is invariant: $\nu(\{x:x\cdot g\in E\})=\nu(E)$
for every Borel set $E\subseteq X$ and every $g\in G$. For $g\in G$ and $\varphi\in\Ltwo(X,\nu)$, the \emph{right
regular representation} is $R(g)\varphi=$ the class of the function $x\mapsto\varphi(x\cdot g)$.
