The map
\[
  \Q^\times\times\R_{>0}\times\Zhat^\times\longrightarrow\A^\times,\qquad(q,r,u)\longmapsto q\cdot(r,u),
\]
is an isomorphism of topological groups, where $\Q^\times$ carries the discrete topology and $(r,u)\in\A^\times$ has
components $r$ at $\infty$ and $u_p$ at $p$. For $x\in\A^\times$ we write $x=q(x)\,(r(x),u(x))$ accordingly; then
$\abs{x}_\A=r(x)$.
