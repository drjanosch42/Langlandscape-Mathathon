Let $G$ be a topological group with a $\sigma$-algebra and $\mu$ a measure on $G$. A \emph{Dirac sequence} on $G$ (with
respect to $\mu$) is a sequence $(f_n)_{n\in\N}$ of continuous functions $f_n\colon G\to\R$ with compact support such
that $f_n\ge0$, $\int_Gf_n\,\dd\mu=1$ for every $n$, and for every neighbourhood $W$ of $1$ there is $N$ with
$\supp f_n\subseteq W$ for all $n\ge N$.
