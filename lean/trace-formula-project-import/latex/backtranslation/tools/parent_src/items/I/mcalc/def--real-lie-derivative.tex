For $X\in\Mat_2(\R)$ and $f\colon\GL_2(\R)\to\C$ put $(D_Xf)(g)=D\tilde f(g)(gX)$, the real directional derivative of $\tilde f$ at $g$ in the direction $gX$ (the Fr\'echet derivative of $\tilde f$ if it exists, and $0$ if not). This is the real part of the Lie action $X\cdot f$ of \cref{I.rep.def:lie-action}.
