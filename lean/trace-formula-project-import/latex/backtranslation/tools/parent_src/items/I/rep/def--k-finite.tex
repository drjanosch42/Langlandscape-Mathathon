For $f\colon\GL_2(\R)\to\C$ and $k\in\GL_2(\R)$ let $\rho(k)f$ and $\lambda(k)f$ be the functions
$(\rho(k)f)(g)=f(gk)$ and $(\lambda(k)f)(g)=f(k^{-1}g)$. The function $f$ is \emph{right $\Kinf$-finite} if the
$\C$-linear span of $\{\rho(k)f:k\in\Kinf\}$ is finite-dimensional, \emph{left $\Kinf$-finite} if the span of
$\{\lambda(k)f:k\in\Kinf\}$ is finite-dimensional, and \emph{bi-$\Kinf$-finite} if the span of the functions
$g\mapsto f(kgk')$, for $k,k'\in\Kinf$, is finite-dimensional.
