For $r\in\R_{>0}$ let $a(r)\in G(\A)$ be the element with $a(r)_\infty=\diag(r,r)$ and $a(r)_p=1$ for all primes $p$.
The \emph{split component of the centre} is $\AGplus=\{a(r):r\in\R_{>0}\}$. It is a subgroup of the centre of $G(\A)$, and
$r\mapsto a(r)$ is an isomorphism of topological groups $\R_{>0}\to\AGplus$.
