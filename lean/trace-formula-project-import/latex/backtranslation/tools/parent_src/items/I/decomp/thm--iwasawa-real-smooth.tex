Let $U=\{X\in\Mat_2(\R):\det X\neq0\}$, and for $X=\begin{psmallmatrix}a&b\\c&d\end{psmallmatrix}\in U$ put
\[
  t_2(X)=(c^2+d^2)^{1/2},\quad t_1(X)=\frac{\det X}{t_2(X)},\quad x(X)=\frac{ac+bd}{c^2+d^2},\quad
  k(X)=\frac1{t_2(X)}\begin{pmatrix}d&-c\\c&d\end{pmatrix}.
\]
These are well defined on $U$, the real functions $t_2$, $t_1$, $x$ and the four entries of $k$ are infinitely
differentiable on the open set $U\subseteq\Mat_2(\R)\cong\R^4$, $t_2>0$ and $t_1\neq0$ on $U$, and for every
$g\in\GL_2(\R)$ the decomposition of \cref{I.decomp.thm:iwasawa-real} is $g=n(x(g))\,\diag(t_1(g),t_2(g))\,k(g)$.
