Every $g\in\GL_2(\R)$ can be written uniquely as
\[
  g=n(x)\,\diag(t_1,t_2)\,k\qquad\text{with }x\in\R,\ t_1\in\R^\times,\ t_2\in\R_{>0},\ k\in\mathrm{SO}(2).
\]
Explicitly, if $g=\begin{psmallmatrix}a&b\\c&d\end{psmallmatrix}$, then
\[
  t_2=(c^2+d^2)^{1/2},\qquad t_1=\frac{\det g}{t_2},\qquad x=\frac{ac+bd}{c^2+d^2},\qquad
  k=\frac1{t_2}\begin{pmatrix}d&-c\\c&d\end{pmatrix}.
\]
