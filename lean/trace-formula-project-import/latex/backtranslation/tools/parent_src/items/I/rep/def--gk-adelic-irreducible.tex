Let $V$ be a $(\mathfrak g,\Kinf)\times G(\Af)$-module (\cref{I.rep.def:gk-finite-adelic-module}) with Lie action
$X\cdot v$, $\Kinf$-action $\kappa$ and $G(\Af)$-action $\sigma_f$. A \emph{submodule} of $V$ is a $\C$-linear subspace
$W\subseteq V$ with $X\cdot w\in W$, $\kappa(k)w\in W$ and $\sigma_f(h)w\in W$ for all $X\in\mathfrak g$, $k\in\Kinf$,
$h\in G(\Af)$ and $w\in W$. The module $V$ is \emph{irreducible} if $V\neq0$ and its only submodules are $0$ and $V$.
