Let $V$ be a $(\mathfrak g,\Kinf)$-module (\cref{I.rep.def:gk-module}) with Lie action $(X,v)\mapsto X\cdot v$ and
$\Kinf$-action $\kappa$. A \emph{$(\mathfrak g,\Kinf)$-submodule} of $V$ is a $\C$-linear subspace $W\subseteq V$ such that
$X\cdot w\in W$ and $\kappa(k)w\in W$ for all $X\in\mathfrak g$, $k\in\Kinf$ and $w\in W$.
