Let $F$ be a non-archimedean local field with residue cardinality $q$ and uniformizer $\unif$. Then
$\abs{\unif}_F=q^{-1}$, and $\abs{u}_F=1$ for $u\in\Ocal_F^\times$. Consequently, for $x=u\unif^n\in F^\times$ with
$u\in\Ocal_F^\times$ and $n\in\Z$, $\abs{x}_F=q^{-n}$; in particular $\abs{x}_F\le1$ if and only if $x\in\Ocal_F$, and
$\abs{x}_F=1$ if and only if $x\in\Ocal_F^\times$.
