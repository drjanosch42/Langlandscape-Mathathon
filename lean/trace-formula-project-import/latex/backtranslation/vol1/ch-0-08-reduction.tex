\begin{tffidelity}

\end{tffidelity}
\end{tfformal}
\begin{proof}[Lean proof]
\emph{Divergence from A.} The hypothesis $C>0$ is not needed (for $C\le0$ the set is empty and $F=\emptyset$ works). Let $\mathcal N(y)$ (\texttt{adelicEntryNorm}) be the sum of the absolute values of the entries of $y_\infty$ times $\prod_p\max_{ij}\norm{y_{ij}}_p$; the entry sum replaces the operator norm of A, since only an upper bound is used. For $\delta\in G(\Q)$ choose $\beta\in B(\Q)$ with $\beta\delta$ having coprime integral bottom row $(m,n)$ (\texttt{exists\_borel\_primitive}); \texttt{bottomRowNorm\_borel\_mul} says the bottom-row norm only changes by a factor $1$ under $B(\Q)$. Applied to $y=x^{-1}$ and the integral row $v=(m,n)$ (adelic norm $(m^2+n^2)^{1/2}$) one gets $(m^2+n^2)^{1/2}\le\mathcal N(x^{-1})\norm{e_2\beta\delta x}_\A\le\mathcal N(x^{-1})C$ (\texttt{primitive\_le}). So $|m|,|n|\le N=\lceil\mathcal N(x^{-1})C\rceil$, and there are finitely many pairs $(m,n)$. For each pair that occurs, pick one representative $\delta_0$ (\texttt{rep}); then $\delta\in B(\Q)\,\delta_0$ because two elements of $G(\Q)$ with the same bottom row differ by an element of $B(\Q)$ (\texttt{mul\_inv\_mem\_borel\_of\_bottom}). The reverse inclusion is the same invariance of the bottom-row norm.
\end{proof}
