\end{theorem}
\begin{tfformal}{X.topgrp.thm:restricted-product-second-countable}
\tfsem{X.topgrp.thm:restricted-product-second-countable}{b0b51cc8165ace18511e3ca390513072615af651f9ba8453630fbc131c9574af}
\tfhyps{X.topgrp.thm:restricted-product-second-countable}{}
\tfbinder{X.topgrp.thm:restricted-product-second-countable}{0}{fe5aea28}{the index type $\iota$}
\tfbinder{X.topgrp.thm:restricted-product-second-countable}{1}{51c6bf8e}{the assumption that the index set $\iota$ is countable (A: ``countable'')}
\tfbinder{X.topgrp.thm:restricted-product-second-countable}{2}{ce532c75}{the family of types $X_i$}
\tfbinder{X.topgrp.thm:restricted-product-second-countable}{3}{b85b1d8c}{the topologies of the $X_i$}
\tfbinder{X.topgrp.thm:restricted-product-second-countable}{4}{a461e99c}{the assumption that every $X_i$ is second countable (A: ``second countable'')}
\tfbinder{X.topgrp.thm:restricted-product-second-countable}{5}{c136b664}{the family of subsets $A_i\subseteq X_i$}
\tfbinder{X.topgrp.thm:restricted-product-second-countable}{6}{9fd77963}{the assumption that every $A_i$ is open (A: ``open'')}
\begin{tffidelity}
The restricted product is Mathlib's \texttt{RestrictedProduct (fun i => X i) (fun i => A i) Filter.cofinite} with its restricted-product topology. The hypothesis that the subsets $A_i$ are open is an explicit argument \texttt{(∀ i, IsOpen (A i))} after $A$; countability of the index set and second countability of the $X_i$ are instance binders. The instance form with \texttt{Fact (∀ i, IsOpen (A i))} is the B-only \cref{X.topgrp.lem:restricted-product-second-countable-instance}.
\end{tffidelity}
\end{tfformal}
\begin{proof}[Lean proof]
For a finite $F\subseteq\iota$, the principal restricted product $\prod'_i[X_i,A_i]_{\mathcal P(F^c)}$ embeds as an open subspace of the restricted product (\texttt{isOpenEmbedding\_inclusion\_principal}) and is second countable, being a subspace of $\prod_iX_i$ (\texttt{isEmbedding\_coe\_of\_principal}). Each point $x$ has all but finitely many coordinates in $A_i$, so lies in the image for some $F$ (\texttt{exists\_inclusion\_eq\_of\_eventually}); as $\iota$ is countable there are countably many finite $F$, and a space covered by countably many open second countable subspaces is second countable (\texttt{secondCountableTopology\_of\_countable\_cover}).
\end{proof}
