### 3.3 `EdgeO` = the tex's edge set

`Vert q = GL₂(ℚ_q) ⧸ (Z · GL₂(ℤ_q))`, `Edge q = GL₂(ℚ_q) ⧸ (Z · Iw_q)`, `o [g] = [g]`, `t [g] = [g α]`,
`α = diag(1, q)`, `EdgeO q = {e // vtype (o e) = 0}` (`Tree/Coset.lean:234–304`). Mathematically `Z · Iw_q =
Z·K ∩ α(Z·K)α⁻¹` is the stabiliser of the ordered pair `(v₀, v₁)` and `GL₂(ℚ_q)` is transitive on ordered adjacent
pairs, so `Edge q` is the set of all oriented edges and `EdgeO q` is the set of geometric edges with the orientation
type `0 →` type `1`: the tex's `E(𝒯_q)`. In Lean this identification is not a statement, but its content is proved:
`SLq_transitive_edge`, `stabilizer_e0 = SL₂ ∩ Iw`, `stabilizer_v0`, `stabilizer_v1`, `GL2Zl_inf_Kalpha` together give
that `e ↦ (oO e, tO e)` is injective on `EdgeO q` (if `s e₀`, `s' e₀` have the same ends then `s⁻¹ s'` fixes `v₀` and
`v₁`, hence lies in `SL₂ ∩ Iw` and fixes `e₀`). So `EdgeO q` is in bijection with the edges of `Tree.graph q`. I
recommend stating this as a lemma (R1, optional); the verdict does not depend on it.
