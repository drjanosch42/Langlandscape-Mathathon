1. CONTEXT
We study whether a homotopical/integral Jacquet-Langlands correspondence exists (definite quaternion algebra B/Q, disc. D,
versus GL_2/Q), via S-arithmetic / amalgam / Borel-Serre arguments. The current study (v4) looks at two NEW groups:
 (a) G = GL_2(B), G(R) = GL_2(H), Gamma = GL_2(R), R a maximal order of B; symmetric space GL_2(H)/(Sp(2)R_{>0}) of dim 5.
     Coefficients V_b = harmonic degree-b part of Sym^b Herm_2(B)_R (Herm_2(H) is 6-dim; V_9 has rank 1210).
 (b) Spin(B^0 + U) = SU(1,1)(B) = Sp(1,1) = Spin(4,1)  (U hyperbolic plane): hyperbolic 4-orbifolds, one cusp per class.
HACS currently does SL_2(Z) / Gamma_0(N) only [C = docs/latex/gl2_contract.tex]; no S-arithmetic, no quaternionic groups.
So these groups are new for you. Please FIRST judge feasibility (a few lines: which cell/presentation model, what it costs),
and only "squeeze in" what fits without disturbing your roadmap. Partial answers (cheapest items only) are very welcome.
Our predictions below are NOT results; each carries a status: [proved] / [sketched] / [conjectural] / [computed-by-hand].
